You've made your first call. Here's what to learn next.

<CardGroup cols={3}>
  <Card title="Find the right endpoint" icon="magnifying-glass" href="/guides/find-endpoint">
    Search the catalog by keyword, or browse it by category.
  </Card>
  <Card title="Page through results" icon="list" href="/guides/paging">
    Send the cursor from each response to get the next page, and use `limit` to keep fewer results.
  </Card>
  <Card title="Handle errors and retries" icon="triangle-exclamation" href="/guides/errors-and-retries">
    Read the error code, retry only when it's safe, and back off.
  </Card>
</CardGroup>

Every endpoint is a `POST` to `https://api.stophy.dev/v1/` followed by its id with dots as slashes: `google.search` is `/v1/google/search`, and `transcript` is `/v1/transcript`. Send a JSON body and a bearer key. The [API reference](/api-reference/introduction) has the full input and output for each one.
