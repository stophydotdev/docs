Give your agent [stophy.dev/agents.md](https://stophy.dev/agents.md). It says how to pick an endpoint and add Stophy to your project.

## Connect over MCP

```bash
claude mcp add --transport http stophy https://api.stophy.dev/mcp
```

The free endpoints work right away. Add your key as a bearer token to use every endpoint, or sign in with your browser at `https://mcp.stophy.dev/mcp`.

<Card title="MCP server" icon="plug" href="/mcp-server">Set up Codex, Claude Code, Cursor, OpenCode or another client.</Card>

## Get a key

Sign up in the [dashboard](https://stophy.dev/signup), create a key, and save it as `STOPHY_API_KEY`. Send it with every API request.
