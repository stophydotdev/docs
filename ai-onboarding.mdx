## Get credentials

Sign up in the [dashboard](https://stophy.dev/signup) and create an API key. Set it as `STOPHY_API_KEY` in your environment. Send the key with every API request. Over MCP you can also start with no key, or sign in with your browser.

**How you might arrive:**

- **Docs:** start in the dashboard to get your key.
- **API `401`:** create a key, or check the key in your `Authorization` header.
- **Direct URL:** follow [agents.md](https://stophy.dev/agents.md), then create a key in the dashboard.

<Card title="Get an API key" icon="key" href="https://stophy.dev/signup">Create an account, then add a key in the dashboard.</Card>

## Set up MCP

Stophy's remote MCP server lets your agent find and call endpoints. It uses Streamable HTTP at `https://api.stophy.dev/mcp`. Start with no key, add a bearer key for every endpoint, or sign in at `https://api.stophy.dev/mcp-oauth`.

<Card title="Set up Stophy MCP" icon="plug" href="/mcp-server">Connect Codex, Claude Code, Cursor, OpenCode, or another MCP client.</Card>
