## Get credentials

A human signs up at [stophy.dev/signup](https://stophy.dev/signup), creates an API key, and stores it as `STOPHY_API_KEY`. New accounts start with 500 free credits. Never print the key, log it, or commit it.

Without a key and without a human, you can still call `web.search`, `youtube.search` and `youtube.transcript` within [free limits](/without-a-key).
