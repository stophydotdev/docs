- **Endpoint:** `ads.search`
- **Returns:** `data` has `results`, `totalMin`, `totalMax`, `advertiserId`, `advertiserName`, `total`.
- **Cost:** 1 credit per call. Failed calls cost nothing.
- **Paging:** Yes. Send the `cursor` from the response to get the next page. See [Page through results](/guides/paging).

On Meta, `mediaType` keeps image, video or text ads. Pinterest takes `advertiser` and rejects `query`. Google takes `query` only when it is a domain. To search Google by name, find the advertiser id with Ads advertisers first. On LinkedIn, `within` limits how recent the ads are.
