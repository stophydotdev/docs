## Request

Exactly one of `listingUrl` or `listingId` is required. A request that sets both, or none, fails with `invalidRequest`.

If successful, the response body contains the standard envelope. `data` contains the listing's details, host, rooms, amenities, ratings and price.

| Field | Type | Description |
| --- | --- | --- |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | Number of reviews Airbnb shows for the stay, the same as total in [Airbnb airbnb Reviews](/api-reference/endpoint/airbnb-reviews). A room in a larger property shares the property's reviews. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `checkIn` | string (date) | First night, as YYYY-MM-DD. Send it with `checkOut` to get the price. Format: `YYYY-MM-DD`. |
| `checkOut` | string (date) | Day you leave, as YYYY-MM-DD. Send it with `checkIn` to get the price. Format: `YYYY-MM-DD`. |
| `guests` | integer | Number of guests. Only stays that fit this many. Must be between 1 and 16. If unset, defaults to `1`. |
| `currency` | string | Currency of every price in the answer and of `minPrice` and `maxPrice`. Acceptable values are `USD`, `EUR`, `GBP`, `JPY`, `CAD`, `AUD`, `CHF`, `MXN` and `BRL`. If unset, defaults to `USD`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
