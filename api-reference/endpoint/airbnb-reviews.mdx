## Response

If successful, the response body contains the standard envelope. `data.results[]` contains a page of the listing's reviews, each with its rating, text and date.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "listingId": "53888412",
    "total": 337,
    "results": [
      {
        "reviewId": "1785576510399038758",
        "rating": 5,
        "text": "Très bel appartement. Très bien localisé au cœur du quartier Alfama. Endroit parfait, près des transports et lieux à…",
        "language": "fr",
        "translatedText": "Very nice apartment. Very well located in the heart of the Alfama district. Perfect location, close to public…",
        "createdAt": "2026-09-29T15:01:47.000Z",
        "authorName": "Isabelle",
        "stayNote": "Stayed a few nights"
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | The total number of matching results, across all pages. |
| `createdAt` | string (ISO 8601) | The creation time, in UTC. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 200. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 200.
