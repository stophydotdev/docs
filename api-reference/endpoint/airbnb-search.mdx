## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `guests` | integer | Number of guests. Only stays that fit this many. Must be between 1 and 16. If unset, defaults to `1`. |
| `minPrice` | integer | Airbnb's own price range minimum: the nightly price after discounts and before taxes, in currency. |
| `maxPrice` | integer | Airbnb's own price range maximum: the nightly price after discounts and before taxes, in currency. |
| `roomType` | string | Airbnb's own Type of place filter: `entireHome` (Entire home) or `privateRoom` (Room). Acceptable values are `entireHome` and `privateRoom`. |
| `currency` | string | Currency of every price in the answer and of `minPrice` and `maxPrice`. Acceptable values are `USD`, `EUR`, `GBP`, `JPY`, `CAD`, `AUD`, `CHF`, `MXN` and `BRL`. If unset, defaults to `USD`. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
