## Response

`data.results` lists the best sellers in the category, in rank order. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "category": "Electronics",
    "results": [
      {
        "rank": 1,
        "productId": "B08JHCVHTY",
        "productUrl": "https://www.amazon.com/dp/B08JHCVHTY",
        "title": "blink plus plan with monthly auto-renewal",
        "imageUrl": "https://images-na.ssl-images-amazon.com/images/I/31YHGbJsldL._AC_UL300_SR300,200_.png",
        "price": 11.99,
        "priceCurrency": "USD",
        "rating": 4.4,
        "reviews": 280840
      }
    ],
    "page": 1
  },
  "creditsUsed": 2,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `page`: The page number this response holds.
- `rating`: Star rating, out of 5.
- `reviews`: How many reviews the rating is based on.
- `rank`: Where the entry sits in the list, starting at 1.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `us`. | One of 21 values, like `us`, `gb` and `de`. Default `us`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 2. Default `1`. |

## Cost and limits

- **Price:** 2 credits per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 2.
