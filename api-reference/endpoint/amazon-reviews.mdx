## Response

If successful, the response body contains the standard envelope. `data` contains `productId`, `results` and `cursor`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "productId": "B0CX23V2ZK",
    "results": [
      {
        "authorName": "MWW",
        "rating": 1,
        "title": "Trash",
        "text": "Apple has really gone down hill. They will eventually intentionally stop supporting the latest operating system, which…",
        "publishedAt": "2026-07-23T00:00:00.000Z",
        "country": "United States",
        "isVerified": true,
        "isVine": false,
        "helpfulVotes": 0
      }
    ],
    "cursor": "9XB9OW7DMjAyNi0xMC0xOFQyMDowMDo1MC43NDc5NjM0MTRaADEw"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | The pagination token. Pass it as `cursor` to retrieve the next page. Omitted on the last page. |
| `publishedAt` | string (ISO 8601) | The day the review was written, at midnight UTC. Amazon gives no time of day. |
| `rating` | integer | The average star rating, on a scale of 1 to 5. |

For every field, see the response schema on this page.

<Note>Returns Amazon's US reviews newest first, 10 per page and up to 100 for each star rating.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `rating` | integer | Restricts results to reviews with this star rating. Must be between 1 and 5. |
| `verifiedOnly` | boolean | Restricts results to reviews from verified purchases. If unset, defaults to `false`. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
