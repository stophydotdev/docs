## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the products, each with its price, rating and review count.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "productId": "B0HDB41H28",
        "productUrl": "https://www.amazon.com/dp/B0HDB41H28",
        "title": "Wireless Earbuds, Bluetooth 5.3 Headphones HiFi Stereo 50H Playback LED Digital Display Ear Buds with ENC Noise…",
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | The total number of matching results, across all pages. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `category` | string | The category to search in, by name or id. |
| `minPrice` | number | The minimum price. |
| `maxPrice` | number | The maximum price. |
| `minRating` | number | Restricts results to products rated at least this high. |
| `brand` | string | Restricts results to products from this brand. |
| `sort` | string | Specifies the order of the products. `avgCustomerReview` puts the highest rated first, not the most reviewed. Acceptable values are `relevance`, `priceLow`, `priceHigh`, `avgCustomerReview`, `newest` and `bestSelling`. If unset, defaults to `relevance`. |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. Accepts one of 21 values, such as `us`, `gb` and `de`. If unset, defaults to `us`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 20. If unset, defaults to `1`. |

## Billing

Each successful request consumes 2 credits, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 20.
