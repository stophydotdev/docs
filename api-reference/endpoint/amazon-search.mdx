## Response

`data.results` lists the products, each with its price, rating and review count. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "productId": "B0HDB41H28",
        "productUrl": "https://www.amazon.com/dp/B0HDB41H28",
        "title": "Wireless Earbuds, Bluetooth 5.3 Headphones HiFi Stereo 50H Playback LED Digital Display Ear Buds with ENC Noise…",
        "imageUrl": "https://m.media-amazon.com/images/I/618n7fFdFXL._AC_UY218_.jpg",
        "price": 18.98,
        "originalPrice": 249.99,
        "priceCurrency": "USD",
        "rating": 4.6,
        "reviews": 270,
        "boughtPastMonth": 4000,
        "isSponsored": false
      }
    ],
    "total": 27654,
    "page": 1
  },
  "creditsUsed": 2,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `page`: The page number this response holds.
- `total`: How many results match in all, not only on this page.
- `rating`: Star rating, out of 5.
- `reviews`: How many reviews the rating is based on.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. | Text. |
| `category` | The category to search in, by name or id. | Text. |
| `minPrice` | Lowest price. | Number, 0 or more. |
| `maxPrice` | Highest price. | Number, 0 or more. |
| `minRating` | Only products rated at least this high. | Number. |
| `brand` | Only products from this brand. | Text. |
| `sort` | How to order the products. `avgCustomerReview` puts the highest rated first, not the most reviewed. | `relevance`, `priceLow`, `priceHigh`, `avgCustomerReview`, `newest` or `bestSelling`. Default `relevance`. |
| `country` | Two-letter country code, like `us`. | One of 21 values, like `us`, `gb` and `de`. Default `us`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 20. Default `1`. |

## Cost and limits

- **Price:** 2 credits per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 20.
