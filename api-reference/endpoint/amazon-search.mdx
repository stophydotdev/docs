- **Endpoint:** `amazon.search`
- **Returns:** `data` has `total`, `results`, `page`.
- **Cost:** 2 credits per call. Failed calls cost nothing.
- **Paging:** Yes. Send `page: 2`, then `3`, until `data.results` is empty. See [Page through results](/guides/paging).

`sort` set to `avgCustomerReview` puts the highest rated first. It does not mean most reviewed.
