## Response

`data.results` lists the suggestions, best first. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "keyword": "best running shoes for women",
        "rank": 1
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `rank`: Where the entry sits in the list, starting at 1.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `us`. | One of 21 values, like `us`, `ca` and `mx`. Default `us`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
