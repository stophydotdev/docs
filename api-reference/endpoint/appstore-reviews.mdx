## Response

If successful, the response body contains the standard envelope. `data.results[]` contains a page of the app's reviews.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "reviewId": "14626635924",
        "rating": 1,
        "title": "Junk",
        "text": "Way too many adds, shows more posts from people that i don’t know than the people im friends with. Oh and did i…",
        "authorName": "JmichaelA1981",
        "publishedAt": "2026-10-04T12:57:24.000Z",
        "isEdited": false
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `rating` | integer | The average star rating, on a scale of 1 to 5. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `sort` | string | Specifies which reviews are returned first. Acceptable values are `newest`, `helpful`, `highest` and `lowest`. If unset, defaults to `newest`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 500. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 500.
