## Response

`data.results` lists a page of the app's reviews. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "reviewId": "14626635924",
        "rating": 1,
        "title": "Junk",
        "text": "Way too many adds, shows more posts from people that i don’t know than the people im friends with. Oh and did i…",
        "authorName": "JmichaelA1981",
        "publishedAt": "2026-10-04T12:57:24.000Z",
        "isEdited": false
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `page`: The page number this response holds.
- `publishedAt`: When it was published, as a UTC time.
- `rating`: Star rating, out of 5.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `us`. | Two letters. |
| `sort` | Which reviews come first. | `newest`, `helpful`, `highest` or `lowest`. Default `newest`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 500. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 500.
