## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `chart` | string | Specifies which chart to read. Acceptable values are `free`, `paid` and `grossing`. If unset, defaults to `free`. |
| `device` | string | The Apple device store to read. Acceptable values are `iphone`, `ipad` and `mac`. If unset, defaults to `iphone`. |
| `genre` | string | Restricts results to apps in this genre. Accepts one of 24 values, such as `business`, `weather` and `utilities`. |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. If unset, defaults to `us`. |
| `limit` | integer | The maximum number of apps to return. Billed at 1 credit per 10 returned. Must be between 1 and 100. |

## Billing

A successful request consumes 1 credit per 10 apps, up to 10 credits. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
