## Options

| Option | What it does | Values |
| --- | --- | --- |
| `chart` | Which chart to read. | `free`, `paid` or `grossing`. Default `free`. |
| `device` | The Apple device store to read. | `iphone`, `ipad` or `mac`. Default `iphone`. |
| `genre` | Only apps in this genre. | One of 24 values, like `business`, `weather` and `utilities`. |
| `country` | Two-letter country code, like `us`. | Two letters. Default `us`. |
| `limit` | Return at most this many apps. You pay 1 credit per 10 returned. | Whole number, 1 to 100. |

## Cost and limits

- **Price:** 1 credit per 10 apps. A call costs 10 credits at most. Failed calls and empty results cost nothing. Send `limit` to get fewer results and pay for fewer.
- **Paging:** None. One call returns everything for the input.
