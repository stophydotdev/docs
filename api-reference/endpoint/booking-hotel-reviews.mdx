## Response

If successful, the response body contains the standard envelope. `data.results[]` contains a page of the hotel's reviews, each with its score, what the guest liked and disliked, room and dates.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `sort` | string | Booking.com's own Sort reviews by: newest, `mostRelevant` or `lowestScore` (lowest scores first). Only newest pages without gaps. The other orders change between requests, so a walk through the pages can miss reviews. Acceptable values are `newest`, `mostRelevant` and `lowestScore`. If unset, defaults to `newest`. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
