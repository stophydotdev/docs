## Response

If successful, the response body contains the standard envelope. `data.results[]` contains a page of the company's open jobs, each with its title, department, location and date.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "jobId": "5813967004",
        "jobUrl": "https://boards.greenhouse.io/figma/jobs/5813967004",
        "title": "Distribution Partner Manager",
        "department": "Business Development",
        "location": "San Francisco, CA • New York, NY • United States",
        "publishedAt": "2026-02-28T00:00:43.000Z",
        "updatedAt": "2026-07-22T09:37:08.000Z",
        "boardUrl": "https://boards.greenhouse.io/figma"
      }
    ],
    "cursor": "zTzqlR4g20"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |

| `cursor` | string | The pagination token. Pass it as `cursor` to retrieve the next page. Omitted on the last page. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
