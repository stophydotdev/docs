## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the listings, each with its title, price, city and photo.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `minPrice` | integer | The minimum price in local currency (e.g., 50). Must be between 0 and 1000000000. |
| `maxPrice` | integer | The maximum price in local currency (e.g., 500). Must be between 0 and 1000000000. |
| `sort` | string | Sort order (newest, `priceLow` or `priceHigh`), relevance by default. Acceptable values are `newest`, `priceLow` and `priceHigh`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
