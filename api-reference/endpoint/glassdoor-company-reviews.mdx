## Response

If successful, the response body contains the standard envelope. `data` contains `companyId`, `total`, `totalAllLanguages`, `results` and `page`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "companyId": "9079",
    "total": 66022,
    "totalAllLanguages": 71507,
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | Reviews written in English. These are the ones this endpoint lists. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 500. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 500.
