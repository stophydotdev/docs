Scrape a Glassdoor company's ratings and details. The company or companyName is identified by its URL, ID or companyName.

## Request

Exactly one of `companyUrl`, `companyId` or `companyName` is required. A request that sets more than one, or none, fails with `invalidRequest`.

## Response

If successful, the response body contains the standard envelope. `data` contains the company's ratings, size, industry and headquarters.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "companyId": "9079",
    "companyUrl": "https://www.glassdoor.com/Overview/Working-at-Google-EI_IE9079.11,17.htm",
```

| Field | Type | Description |
| --- | --- | --- |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | Reviews in every language. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
