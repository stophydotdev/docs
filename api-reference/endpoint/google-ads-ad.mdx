## Response

`data` has the ad's advertiser, format and creative, and the countries it ran in. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "adId": "CR00462730911658541057",
    "adUrl": "https://adstransparency.google.com/advertiser/AR16735076323512287233/creative/CR00462730911658541057",
    "advertiserId": "AR16735076323512287233",
    "advertiserName": "Nike, Inc.",
    "advertiserUrl": "https://adstransparency.google.com/advertiser/AR16735076323512287233",
    "format": "text",
    "lastShownAt": "2026-10-05T20:27:35.000Z",
    "imageUrl": "https://tpc.googlesyndication.com/archive/simgad/5743239130676952852",
    "advertiserCountry": "US",
    "advertiserIsVerified": true,
    "paidBy": "Nike, Inc.",
    "variations": [
      {
        "imageUrl": "https://tpc.googlesyndication.com/archive/simgad/5743239130676952852"
      }
    ],
    "regions": [
      {
        "country": "US",
        "lastShownAt": "2026-09-01T00:00:00.000Z"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

Fields to know:

- `lastShownAt`: The last day the ad was shown.
- `paidBy`: Who paid for the ad.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `advertiserId` | Advertiser id, like `AR18378488041124659201`. Send it with `adId`. A link already has it. | Text. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
