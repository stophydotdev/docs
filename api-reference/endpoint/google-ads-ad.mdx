## Response

If successful, the response body contains the standard envelope. `data` contains the ad's advertiser, format and creative, and the countries it ran in.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "adId": "CR00462730911658541057",
    "adUrl": "https://adstransparency.google.com/advertiser/AR16735076323512287233/creative/CR00462730911658541057",
    "advertiserId": "AR16735076323512287233",
    "advertiserName": "Nike, Inc.",
    "advertiserUrl": "https://adstransparency.google.com/advertiser/AR16735076323512287233",

      {
        "imageUrl": "https://tpc.googlesyndication.com/archive/simgad/5743239130676952852"
```

| Field | Type | Description |
| --- | --- | --- |
| `lastShownAt` | string (ISO 8601) | The last day the ad was shown. |
| `paidBy` | string | The entity that paid for the ad. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `advertiserId` | string | Advertiser id, such as `AR18378488041124659201`. Requires `adId`. A link already has it. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
