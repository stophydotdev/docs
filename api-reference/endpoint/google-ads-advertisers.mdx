## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the advertisers that match, each with a range for how many ads it runs.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "advertiserId": "AR06641858037806006273",
        "advertiserName": "Nike",
        "advertiserCountry": "KE",
        "advertiserUrl": "https://adstransparency.google.com/advertiser/AR06641858037806006273",
        "isVerified": false,
        "adsMin": 1,
        "adsMax": 1
      }
    ],
    "domains": ["nike.sk"]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `adsMin` | integer | With `adsMax`, the range for how many ads the advertiser runs. |
| `domains` | string[] | Domains that match the query. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Country code like de. Advertisers are matched on ads shown in this country, wherever the advertiser is based, and `adsMin` and `adsMax` count only the ads shown there. |
| `limit` | integer | The number of advertisers to ask Google for, 1 to 100. Google ranks the list for the count you ask, so a larger limit is not the same list with more rows added, and there are no further pages. Fewer come back when Google has fewer matches. Must be between 1 and 100. If unset, defaults to `10`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
