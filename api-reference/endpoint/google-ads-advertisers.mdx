## Response

`data.results` lists the advertisers that match, each with a range for how many ads it runs. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "advertiserId": "AR06641858037806006273",
        "advertiserName": "Nike",
        "advertiserCountry": "KE",
        "advertiserUrl": "https://adstransparency.google.com/advertiser/AR06641858037806006273",
        "isVerified": false,
        "adsMin": 1,
        "adsMax": 1
      }
    ],
    "domains": ["nike.sk"]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `adsMin`: With `adsMax`, the range for how many ads the advertiser runs.
- `domains`: Domains that match your query.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `de`. Advertisers match on ads shown there, wherever they are based. | Two letters. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
