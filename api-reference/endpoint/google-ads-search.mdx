## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the ads, each with its advertiser and the days it ran.

The following example is a real response, truncated: each list shows one item and long strings are cut.

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | The pagination token. Pass it as `cursor` to retrieve the next page. Omitted on the last page. |
| `totalMin` | integer | With `totalMax`, the range for the number of matching ads. |
| `firstShownAt` | string (ISO 8601) | When Google first showed the ad. |
| `lastShownAt` | string (ISO 8601) | The last day the ad was shown. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | A domain such as `nike.com`. |
| `advertiser` | string | An advertiser id from Google ads advertisers. |
| `domain` | string | A domain such as `nike.com`. |
| `country` | string | Two-letter country code, such as `de`. Only ads shown there are returned. |
| `mediaType` | string | Restricts results to ads of this type. Acceptable values are `text`, `image` and `video`. |
| `platform` | string | Google's own Platform filter: where the ad was shown. Google leaves out ads shown before 4 September 2023 when it is set. Acceptable values are `search`, `youtube`, `play`, `maps` and `shopping`. |
| `shownFrom` | string (date) | Restricts results to ads shown on or after this day. Format: `YYYY-MM-DD`. |
| `shownTo` | string (date) | Restricts results to ads shown on or before this day. Format: `YYYY-MM-DD`. |
| `cursor` | string | The pagination token from the previous response. |

<Note>The Google ad library does not support keyword search. To search by advertiser name, first resolve the advertiser ID with [Google advertisers](/api-reference/endpoint/google-ads-advertisers).</Note>

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
