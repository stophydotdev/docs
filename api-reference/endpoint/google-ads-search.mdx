## Response

`data.results` lists the ads, each with its advertiser and the days it ran. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "adId": "CR00462730911658541057",

    ],

  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

Fields to know:

- `cursor`: Send it back as `cursor` to get the next page. The last page has none.
- `totalMin`: With `totalMax`, the range for how many ads match.
- `firstShownAt`: The first day the ad was shown.
- `lastShownAt`: The last day the ad was shown.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | A domain like `nike.com`. | Text. |
| `advertiser` | An advertiser id from Google ads advertisers. | Text. |
| `domain` | A domain like `nike.com`. | Text. |
| `country` | Two-letter country code, like `de`. Only ads shown there are returned. | Two letters. |
| `mediaType` | Only ads of this type. | `text`, `image` or `video`. |
| `platform` | Where the ad was shown. | `search`, `youtube`, `play`, `maps` or `shopping`. |
| `shownFrom` | Only ads shown on or after this day. | Date, `YYYY-MM-DD`. |
| `shownTo` | Only ads shown on or before this day. | Date, `YYYY-MM-DD`. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

Google's ad library does not search by keyword. To search by name, find the advertiser id with [Google advertisers](/api-reference/endpoint/google-ads-advertisers) first.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
