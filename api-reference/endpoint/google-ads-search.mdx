- **Endpoint:** `google.ads.search`
- **Returns:** `data` has `totalMin`, `totalMax`, `results`.
- **Cost:** 1 credit per call. Failed calls cost nothing.
- **Paging:** Yes. Send the `cursor` from the response to get the next page. See [Page through results](/guides/paging).

Takes a domain in `query` or `domain`, or an `advertiser`. Google's library does not search by keyword. To search by name, find the advertiser id with Google Ads advertisers first.
