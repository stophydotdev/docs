## Response

If successful, the response body contains the standard envelope. `data` contains Google's answer in `answer` and the pages it cites in `sources`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "query": "What is the best CRM for a small business?",
    "answer": "HubSpot CRM, Zoho CRM, and monday CRM are widely considered the best CRM options for small businesses due to their…",
    "sources": [
      {
        "url": "https://slack.com/blog/crm/best-crm-for-small-business",
        "title": "slack.com"
      }
    ]
  },
  "creditsUsed": 2,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| `answer` | string | The answer text returned by Google. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `language` | string | The language of the results, as a two-letter ISO 639-1 code such as `en`. |

## Billing

Each successful request consumes 2 credits, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
