## Response

`data` has Google's answer in `answer` and the pages it cites in `sources`. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "query": "What is the best CRM for a small business?",
    "answer": "HubSpot CRM, Zoho CRM, and monday CRM are widely considered the best CRM options for small businesses due to their…",
    "sources": [
      {
        "url": "https://slack.com/blog/crm/best-crm-for-small-business",
        "title": "slack.com"
      }
    ]
  },
  "creditsUsed": 2,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `answer`: Google's answer, as text.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `us`. | Two letters. |
| `language` | Two-letter language code, like `en` or `pt`. | Two letters. |

## Cost and limits

- **Price:** 2 credits per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
