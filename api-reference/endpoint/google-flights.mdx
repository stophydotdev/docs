## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the flight options, each with its price, airlines, stops, times and legs.

| Field | Type | Description |
| --- | --- | --- |
| `price` | number | Total fare in USD for all adults together. For a round trip it covers both directions. |
| `legs` | object[] | The outbound journey only, including a return search. |
| `departureLocalTime` | string | Local time at the airport, YYYY-MM-DDTHH:mm, no time zone. |
| `isBest` | boolean | `true` for the options Google marks as best. |
| `durationSeconds` | integer | The duration, in seconds. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `returnDate` | string | The return date. Leave it out for a one-way trip. Format: `YYYY-MM-DD`. |
| `adults` | integer | The number of adults. Must be between 1 and 9. If unset, defaults to `1`. |
| `cabin` | string | The cabin class. Acceptable values are `economy`, `premiumEconomy`, `business` and `first`. If unset, defaults to `economy`. |
| `stops` | string | The number of stops to allow. Acceptable values are `any`, `nonstop`, `oneStopOrFewer` and `twoStopsOrFewer`. If unset, defaults to `any`. |
| `airlines` | string[] | Restricts results to these airlines, as codes such as `KQ` or `EK`. Accepts up to 10 values. |
| `carryOnBags` | integer | Include this many carry-on bags in the price. Must be between 0 and 1. If unset, defaults to `0`. |
| `checkedBags` | integer | Include this many checked bags in the price. Must be between 0 and 2. If unset, defaults to `0`. |
| `maxPrice` | integer | The maximum price, in USD, for all adults. |
| `departureTime` | object | Limit the outbound departure to these hours of the day. An object with `earliest` and `latest`, each an hour from 0 to 24. |
| `arrivalTime` | object | Limit the outbound arrival to these hours of the day. An object with `earliest` and `latest`, each an hour from 0 to 24. |
| `maxDurationHours` | integer | Longest trip, in hours. Must be between 1 and 48. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
