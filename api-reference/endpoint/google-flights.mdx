Fields to know:

- `price`: Total fare in USD for all adults together. For a round trip it covers both directions.
- `legs`: The outbound journey only, including a return search.
- `departureLocalTime`: Local time at the airport, YYYY-MM-DDTHH:mm, no time zone.
- `isBest`: True for the options Google marks as best.
- `durationSeconds`: Length in seconds.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `returnDate` | The return date. Leave it out for a one-way trip. | Date, `YYYY-MM-DD`. |
| `adults` | How many adults. | Whole number, 1 to 9. Default `1`. |
| `cabin` | The cabin class. | `economy`, `premiumEconomy`, `business` or `first`. Default `economy`. |
| `stops` | How many stops to allow. | `any`, `nonstop`, `oneStopOrFewer` or `twoStopsOrFewer`. Default `any`. |
| `airlines` | Only these airlines, as codes like `KQ` or `EK`. | List of text, up to 10. |
| `carryOnBags` | Include this many carry-on bags in the price. | Whole number, 0 to 1. Default `0`. |
| `checkedBags` | Include this many checked bags in the price. | Whole number, 0 to 2. Default `0`. |
| `maxPrice` | Highest price, in USD, for all adults. | Whole number. |
| `departureTime` | Limit the outbound departure to these hours of the day. | Object with `earliest` and `latest`, in hours from 0 to 24. |
| `arrivalTime` | Limit the outbound arrival to these hours of the day. | Object with `earliest` and `latest`, in hours from 0 to 24. |
| `maxDurationHours` | Longest trip, in hours. | Whole number, 1 to 48. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
