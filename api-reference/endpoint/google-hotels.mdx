## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the hotels, each with its price per night, total price, rating and amenities.

The following example is a real response, truncated: each list shows one item and long strings are cut.

| Field | Type | Description |
| --- | --- | --- |
| `price` | number | The minimum price per night. |
| `totalPrice` | number | For the whole stay, with taxes and fees. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `checkIn` | string (date) | The check-in date. Defaults to tomorrow. Format: `YYYY-MM-DD`. |
| `checkOut` | string (date) | The check-out date. Defaults to one night after `checkIn`. Format: `YYYY-MM-DD`. |
| `adults` | integer | The number of adults. Must be between 1 and 12. If unset, defaults to `2`. |
| `childrenAges` | integer[] | One age for each child, such as `[7, 12]`. Accepts up to 8 values. |
| `currency` | string | Three-letter currency code, such as `USD`. If unset, defaults to `USD`. |
| `minPrice` | integer | The minimum price per night. |
| `maxPrice` | integer | The maximum price per night. |
| `minRating` | string | Restricts results to hotels with at least this guest rating. Acceptable values are `3.5+`, `4+` and `4.5+`. |
| `hotelClass` | integer[] | Restricts results to hotels with these star ratings, such as `[4, 5]`. Accepts up to 4 values. |
| `amenities` | string[] | Restricts results to hotels that offer every one of these. Accepts one of 19 values, such as `freeWifi`, `freeBreakfast` and `restaurant`. |
| `propertyTypes` | string[] | Restricts results to these kinds of property. Acceptable values are `beachHotels`, `boutiqueHotels`, `hostels`, `inns`, `motels`, `resorts`, `spaHotels`, `bedAndBreakfasts`, `other` and `apartmentHotels`. |
| `freeCancellation` | boolean | Restricts results to hotels that offer free cancellation. If unset, defaults to `false`. |
| `specialOffers` | boolean | Restricts results to hotels with special offers. If unset, defaults to `false`. |
| `sort` | string | Specifies the order of the hotels. Acceptable values are `relevance`, `lowestPrice`, `highestRating` and `mostReviewed`. If unset, defaults to `relevance`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 10. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 10.
