## Response

`data.results` lists the hotels, each with its price per night, total price, rating and amenities. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "checkIn": "2026-11-19",
    "checkOut": "2026-11-20",
    "results": [
      {
        "name": "Santa Luzia BB - HOrigem - Double Room, River View",
        "hotelId": "ChkQicjQ0reM7_U9Gg0vZy8xMXo0Y25fNDlzEAI",
        "hotelUrl": "https://www.google.com/travel/hotels/entity/ChkQicjQ0reM7_U9Gg0vZy8xMXo0Y25fNDlzEAI?hl=en&gl=us&curr=USD&ts=CAESCgoCCAM…",
        "price": 76,
        "totalPrice": 80,
        "priceCurrency": "USD",
        "rating": 5,
        "reviews": 8,
        "amenities": ["Sleeps 2", "7 bedrooms"],
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `price`: Lowest price per night.
- `totalPrice`: For the whole stay, with taxes and fees.
- `page`: The page number this response holds.
- `position`: Where the result sits in the list, starting at 1.
- `rating`: Star rating, out of 5.
- `reviews`: How many reviews the rating is based on.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `checkIn` | The check-in date. Defaults to tomorrow. | Date, `YYYY-MM-DD`. |
| `checkOut` | The check-out date. Defaults to one night after `checkIn`. | Date, `YYYY-MM-DD`. |
| `adults` | How many adults. | Whole number, 1 to 12. Default `2`. |
| `childrenAges` | One age for each child, like `[7, 12]`. | List of whole numbers, up to 8. |
| `currency` | Three-letter currency code, like `USD`. | Text. Default `USD`. |
| `minPrice` | Lowest price per night. | Whole number. |
| `maxPrice` | Highest price per night. | Whole number. |
| `minRating` | Only hotels with at least this guest rating. | `3.5+`, `4+` or `4.5+`. |
| `hotelClass` | Only hotels with these star ratings, like `[4, 5]`. | List of whole numbers, up to 4. |
| `amenities` | Only hotels that offer every one of these. | List of One of 19 values, like `freeWifi`, `freeBreakfast` and `restaurant`. |
| `propertyTypes` | Only these kinds of property. | List of `beachHotels`, `boutiqueHotels`, `hostels`, `inns`, `motels`, `resorts`, `spaHotels`, `bedAndBreakfasts`, `other` or `apartmentHotels`. |
| `freeCancellation` | Only hotels you can cancel for free. | `true` or `false`. Default `false`. |
| `specialOffers` | Only hotels with special offers. | `true` or `false`. Default `false`. |
| `sort` | How to order the hotels. | `relevance`, `lowestPrice`, `highestRating` or `mostReviewed`. Default `relevance`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 10. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 10.
