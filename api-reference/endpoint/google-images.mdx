## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the images, each with its full-size link and the page it comes from.

The following example is illustrative.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "imageUrl": "https://images.example.com/golden-retriever-puppy.jpg",
        "title": "Golden retriever puppy in the grass",
        "pageUrl": "https://www.example.com/dog-breeds/golden-retriever",
        "source": "example.com",
        "width": 1600,
        "height": 1067,
        "thumbnailUrl": "https://images.example.com/thumbs/golden-retriever-puppy.jpg",
        "position": 1
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `position` | integer | The 1-based position of the result in the list. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `language` | string | The language of the results, as a two-letter ISO 639-1 code such as `en`. |
| `size` | string | Restricts results to images of this size. Acceptable values are `large`, `medium` and `icon`. |
| `type` | string | The kind of image. Acceptable values are `clipArt`, `lineDrawing` and `gif`. |
| `time` | string | Restricts results to images from this period. Acceptable values are `past24Hours` and `pastWeek`. |
| `usageRights` | string | Restricts results to images with this license. Acceptable values are `creativeCommons` and `commercial`. |
| `limit` | integer | The maximum number of images to return. Billed at 1 credit per 10 returned. Must be between 1 and 100. |

## Billing

A successful request consumes 1 credit per 10 images, up to 10 credits. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
