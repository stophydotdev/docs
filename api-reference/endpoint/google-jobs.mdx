## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the openings, each with its company, location and links to apply.

| Field | Type | Description |

| `cursor` | string | The pagination token. Pass it as `cursor` to retrieve the next page. Omitted on the last page. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `location` | string | City or area, such as Austin, TX. |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. If unset, defaults to `us`. |
| `language` | string | The language of the results, as a BCP 47 tag such as `en` or `pt-BR`. If unset, defaults to `en`. |
| `datePosted` | string | Restricts results to jobs posted in this period. Acceptable values are `yesterday`, `last3Days`, `lastWeek` and `lastMonth`. |
| `jobType` | string | Restricts results to this type of job. Acceptable values are `fullTime`, `partTime`, `contract` and `internship`. |
| `remote` | boolean | Restricts results to remote jobs. If unset, defaults to `false`. |
| `noDegree` | boolean | Restricts results to jobs that need no degree. If unset, defaults to `false`. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
