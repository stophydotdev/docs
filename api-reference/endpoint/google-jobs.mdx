## Response

`data.results` lists the openings, each with its company, location and links to apply. Here is a sample response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "jobId": "eyJqb2JfdGl0bGUiOiJTb2Z0d2FyZSBFbmdpbmVlciJ9",
        "title": "Software Engineer",
        "companyName": "Example Corp",
        "location": "Austin, TX",
        "via": "Example Jobs",
        "publishedAt": "2026-10-01T00:00:00.000Z",
        "jobType": "Full-time",
        "salary": "140K–170K a year",
        "benefits": ["Health insurance", "Paid time off"],
        "apply": [

        ],
        "qualifications": ["3 years of experience"],
        "responsibilities": ["Build and ship features"],
        "description": "Build and run the services behind our product.",
        "jobUrl": "https://www.google.com/search?q=software+engineer&ibp=htl;jobs",
        "position": 1
      }
    ],
    "cursor": "CgJUWBIFSm9icxo"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `cursor`: Send it back as `cursor` to get the next page. The last page has none.
- `via`: The site Google found the post on.
- `salary`: As Google shows it, like 140K–170K a year.
- `publishedAt`: Approximate: Google shows how long ago.
- `position`: Where the result sits in the list, starting at 1.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `location` | City or area, like Austin, TX. | Text. |
| `country` | Two-letter country code, like `us`. | Two letters. Default `us`. |
| `language` | Language code, like `en` or `pt-BR`. | Text. Default `en`. |
| `datePosted` | Only jobs posted in this period. | `yesterday`, `last3Days`, `lastWeek` or `lastMonth`. |
| `jobType` | Only this type of job. | `fullTime`, `partTime`, `contract` or `internship`. |
| `remote` | Only remote jobs. | `true` or `false`. Default `false`. |
| `noDegree` | Only jobs that need no degree. | `true` or `false`. Default `false`. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
