Fields to know:

- `page`: The page number this response holds.
- `rating`: Star rating, out of 5.
- `reviews`: How many reviews the rating is based on.
- `openStatus`: Whether the place is open now, as Google words it.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `minRating` | Only places rated at least this high. | `2`, `2.5`, `3`, `3.5`, `4` or `4.5`. |
| `openNow` | Only places open at the time of the search. | `true` or `false`. Default `false`. |
| `country` | Two-letter country code, like `us`. | Two letters. Default `us`. |
| `language` | Language code, like `en` or `pt-BR`. | Text. Default `en`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 10. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 10.
