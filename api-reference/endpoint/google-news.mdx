## Response

`data.results` lists the articles, each with its publisher and time. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "url": "https://www.reuters.com/business/nvidia-broadcom-shielded-ai-power-crunch-hits-chip-supply-chain-says-morgan-2026-10-05/",
        "title": "Nvidia, Broadcom shielded as AI power crunch hits chip supply chain, says Morgan Stanley",
        "source": "Reuters",
        "description": "Nvidia and Broadcom are relatively insulated from a worsening US data-center power crunch, but any ​resultant delay in …",
        "publishedAt": "2026-10-05T14:15:59.000Z",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `source`: Publication that ran the article.
- `page`: The page number this response holds.
- `position`: Where the result sits in the list, starting at 1.
- `publishedAt`: When the article was published.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. Send `query` or `topic`, not both. | Text. |
| `topic` | The top 10 headlines in one section, instead of a search. Send `query` or `topic`, not both. | `world`, `nation`, `business`, `technology`, `entertainment`, `sports`, `science` or `health`. |
| `country` | Two-letter country code, like `us`. | Two letters. |
| `language` | Two-letter language code, like `en` or `pt`. | Two letters. |
| `includeDomains` | Only results from these domains. | List of text, up to 10. |
| `excludeDomains` | Leave out results from these domains. | List of text, up to 10. |
| `time` | Only results from this period. Leave it out for any time. | `pastHour`, `past24Hours`, `pastWeek`, `pastMonth` or `pastYear`. |
| `sort` | Order by relevance or newest first. | `relevance` or `newest`. Default `relevance`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 20. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 20.
