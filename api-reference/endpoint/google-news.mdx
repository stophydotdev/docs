## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the articles, each with its publisher and time.

| Field | Type | Description |
| --- | --- | --- |
| `source` | string | Publication that ran the article. |
| `page` | integer | The page number of this response. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. Mutually exclusive: set either `query` or `topic`. |
| `topic` | string | The top 10 headlines in one section, instead of a search. Mutually exclusive: set either `query` or `topic`. Acceptable values are `world`, `nation`, `business`, `technology`, `entertainment`, `sports`, `science` and `health`. |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `language` | string | The language of the results, as a two-letter ISO 639-1 code such as `en`. |
| `includeDomains` | string[] | Restricts results to results from these domains. Accepts up to 10 values. |
| `excludeDomains` | string[] | Leave out results from these domains. Accepts up to 10 values. |
| `time` | string | Restricts results to results from this period. Leave it out for any time. Acceptable values are `pastHour`, `past24Hours`, `pastWeek`, `pastMonth` and `pastYear`. |
| `sort` | string | Order by relevance or newest first. Acceptable values are `relevance` and `newest`. If unset, defaults to `relevance`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 20. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 20.
