## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the patents, each with its owner, inventor, dates and link.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `inventor` | string | Restricts results to patents by this inventor. |
| `assignee` | string | Restricts results to patents owned by this company or person. |
| `office` | string | Patent office, such as `US`, `EP`, `WO`, `CN` or `JP`. |
| `language` | string | The language of the patents. Accepts one of 16 values, such as `english`, `german` and `chinese`. |
| `dateType` | string | Specifies the date that `before` and `after` are compared against. Acceptable values are `priority`, `filing` and `publication`. If unset, defaults to `priority`. |
| `after` | string (date) | Restricts results to patents dated after this day. `dateType` picks which date counts. Format: `YYYY-MM-DD`. |
| `before` | string (date) | Restricts results to patents dated before this day. `dateType` picks which date counts. Format: `YYYY-MM-DD`. |
| `status` | string | Granted patents or applications. Acceptable values are `grant` and `application`. |
| `type` | string | Patents or designs. Acceptable values are `patent` and `design`. |
| `litigation` | string | Restricts results to patents with related litigation (`has`), or with none known (`none`). Acceptable values are `has` and `none`. |
| `sort` | string | Specifies the order of the patents. Acceptable values are `relevance`, `newest` and `oldest`. If unset, defaults to `relevance`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 100. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 100.
