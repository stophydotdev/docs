## Response

`data.results` lists the patents, each with its owner, inventor, dates and link. Here is a real response, shortened: lists show one row and long text is cut.

{
  "success": true,

Fields to know:

- `patentId`: Publication number, like US11993294B2.
- `page`: The page number this response holds.
- `position`: Where the result sits in the list, starting at 1.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. | Text. |
| `inventor` | Only patents by this inventor. | Text. |
| `assignee` | Only patents owned by this company or person. | Text. |
| `office` | Patent office, like `US`, `EP`, `WO`, `CN` or `JP`. | Two letters. |
| `language` | The language of the patents. | One of 16 values, like `english`, `german` and `chinese`. |
| `dateType` | Which date `before` and `after` compare to. | `priority`, `filing` or `publication`. Default `priority`. |
| `after` | Only patents dated after this day. `dateType` picks which date counts. | Date, `YYYY-MM-DD`. |
| `before` | Only patents dated before this day. `dateType` picks which date counts. | Date, `YYYY-MM-DD`. |
| `status` | Granted patents or applications. | `grant` or `application`. |
| `type` | Patents or designs. | `patent` or `design`. |
| `litigation` | Only patents with related litigation (`has`), or with none known (`none`). | `has` or `none`. |
| `sort` | How to order the patents. | `relevance`, `newest` or `oldest`. Default `relevance`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 100. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 100.
