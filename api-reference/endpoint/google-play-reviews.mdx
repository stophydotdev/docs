Scrape a Google Play app's reviews. The app is identified by its URL or ID.

## Request

Exactly one of `appUrl` or `appId` is required. A request that sets both, or none, fails with `invalidRequest`.

<Note>This endpoint can be called without an API key, subject to per-address limits. Pagination requires a key.</Note>

## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the app's reviews, each with its rating, text and app version.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | The language of the results, as a BCP 47 tag such as `en` or `pt-BR`. If unset, defaults to `en`. |
| `sort` | string | Specifies which reviews are returned first. Acceptable values are `newest`, `relevance` and `highest`. If unset, defaults to `newest`. |
| `rating` | integer | Restricts results to reviews with this many stars. Must be between 1 and 5. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
