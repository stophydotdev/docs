## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. If unset, defaults to `us`. |
| `language` | string | The language of the results, as a BCP 47 tag such as `en` or `pt-BR`. If unset, defaults to `en`. |
| `limit` | integer | The maximum number of apps to return. Billed at 1 credit per 10 returned. Must be between 1 and 50. |

## Billing

A successful request consumes 1 credit per 10 apps, up to 5 credits. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
