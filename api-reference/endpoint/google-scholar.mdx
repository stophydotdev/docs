## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the papers, books and cases, each with its authors, year and the number of works that cite it.

The following example is a real response, truncated: each list shows one item and long strings are cut.

| Field | Type | Description |
| --- | --- | --- |
| `citesId` | string | Pass it as `citesId` to list the works that cite this one. |
| `citations` | integer | The number of works cite this one. |
| `format` | string | Scholar's tag, such as [PDF] or [BOOK]. |
| `publication` | string | Journal or venue; the case citation for case law. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `citesId` | string | A result's `citesId`. Lists the works that cite it. |
| `yearFrom` | integer | Restricts results to works from this year on. Must be between 1700 and 2027. |
| `yearTo` | integer | Restricts results to works up to this year. Must be between 1700 and 2027. |
| `sort` | string | Specifies the order of the results. `newest` lists recent additions first. Acceptable values are `relevance` and `newest`. If unset, defaults to `relevance`. |
| `type` | string | Any type, review articles or case law. Acceptable values are `any`, `reviewArticles` and `caseLaw`. If unset, defaults to `any`. |
| `includePatents` | boolean | Include patents in the results. If unset, defaults to `false`. |
| `includeCitations` | boolean | Include works that Scholar knows only from citations. If unset, defaults to `true`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 20. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 20.
