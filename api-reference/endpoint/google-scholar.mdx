## Response

`data.results` lists the papers, books and cases, each with its authors, year and the number of works that cite it. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "title": "Seven-year efficacy of RTS, S/AS01 malaria vaccine among young African children",
        "url": "https://www.nejm.org/doi/abs/10.1056/NEJMoa1515257",
        "format": "pdf",
        "authors": ["A Olotu", "G Fegan"],
        "publication": "England Journal of …",
        "year": 2016,
        "publisher": "Mass Medical Soc",
        "snippet": "… In an analysis that was not prespecified, the malaria exposure of each child was estimated … of malaria among…",
        "citations": 618,
        "citesId": "15871362944033457094",
        "versions": 14,
        "pdfUrl": "https://www.nejm.org/doi/pdf/10.1056/NEJMoa1515257",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `citesId`: Send as `citesId` to list the works that cite this one.
- `citations`: How many works cite this one.
- `format`: Scholar's tag, like [PDF] or [BOOK].
- `publication`: Journal or venue; the case citation for case law.
- `page`: The page number this response holds.
- `position`: Where the result sits in the list, starting at 1.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. | Text. |
| `citesId` | A result's `citesId`. Lists the works that cite it. | Text. |
| `yearFrom` | Only works from this year on. | Whole number, 1700 to 2027. |
| `yearTo` | Only works up to this year. | Whole number, 1700 to 2027. |
| `sort` | How to order the results. `newest` lists recent additions first. | `relevance` or `newest`. Default `relevance`. |
| `type` | Any type, review articles or case law. | `any`, `reviewArticles` or `caseLaw`. Default `any`. |
| `includePatents` | Include patents in the results. | `true` or `false`. Default `false`. |
| `includeCitations` | Include works that Scholar knows only from citations. | `true` or `false`. Default `true`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 20. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 20.
