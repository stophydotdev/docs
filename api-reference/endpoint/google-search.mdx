## Response

`data` has the web results in `results`, Google's AI Overview when it shows one, related questions and related searches. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "aiOverview": {
      "text": "The best project management software depends on your team's specific workflow, size, and goals, with top platforms like…"
    },
    "results": [
      {
        "type": "web",
        "url": "https://www.reddit.com/r/projectmanagement/comments/1dogwhv/looking_for_a_project_management_software_with/",
        "title": "Looking for a project management software with specific ...",
        "description": "Microsoft Access, Smartsuite, NocoDB, Fibery, Zoho Creator, Baserow), Asana is capable of this. Use Monday.com. Look at…",
        "position": 1
      },
      {
        "type": "post",
        "url": "https://www.linkedin.com/pulse/12-must-have-tools-project-managers-successful-project-managers-sszdf",
        "text": "12 Must-Have Tools for Project Managers",
        "site": "LinkedIn",
        "authorName": "Successful Project Managers",
        "publishedAt": "2026-09-17T07:00:00.000Z",
        "position": 5
      }
    ],
    "peopleAlsoAsk": [
      {
        "question": "Which is the most popular project management software?"
      }
    ],
    "relatedSearches": ["Best project management software reddit"],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `type`: What the row is: `web`, `news`, `video` or `post`.
- `site`: Where the result was found, like YouTube or Reddit.
- `publishedAt`: When it was published. For videos it is approximate, because Google shows only how long ago.
- `page`: The page number this response holds.
- `position`: Where the result sits in the list, starting at 1.
- `aiOverview`: Google's AI Overview. Left out when Google shows none.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `us`. | Two letters. |
| `language` | Two-letter language code, like `en` or `pt`. | Two letters. |
| `includeDomains` | Only results from these domains. | List of text, up to 10. |
| `excludeDomains` | Leave out results from these domains. | List of text, up to 10. |
| `time` | Only results from this period. Leave it out for any time. | `pastHour`, `past24Hours`, `pastWeek`, `pastMonth` or `pastYear`. |
| `verbatim` | Search the exact words, with no spelling fixes. | `true` or `false`. Default `false`. |
| `fileType` | Only files of this type. | One of 11 values, like `pdf`, `doc` and `docx`. |
| `safeSearch` | Hide explicit results. | `true` or `false`. Default `false`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 100. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 100. Without an API key there is no paging.
