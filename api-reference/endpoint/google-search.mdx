## Response

If successful, the response body contains the standard envelope. `data` contains the web results in `results`, Google's AI Overview when it shows one, related questions and related searches.

The following example is a real response, truncated: each list shows one item and long strings are cut.

  "data": {
    "aiOverview": {
      "text": "The best project management software depends on your team's specific workflow, size, and goals, with top platforms…"

| Field | Type | Description |
| --- | --- | --- |
| `type` | string | The kind of item: `web`, `news`, `video` or `post`. |
| `site` | string | Where the result was found, such as YouTube or Reddit. |
| `publishedAt` | string (ISO 8601) | When it was published. For videos it is approximate, because Google shows only how long ago. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |
| `aiOverview` | object | The Google AI Overview. Omitted when Google does not display one. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `language` | string | The language of the results, as a two-letter ISO 639-1 code such as `en`. |
| `includeDomains` | string[] | Restricts results to results from these domains. Accepts up to 10 values. |
| `excludeDomains` | string[] | Leave out results from these domains. Accepts up to 10 values. |
| `time` | string | Restricts results to results from this period. Leave it out for any time. Acceptable values are `pastHour`, `past24Hours`, `pastWeek`, `pastMonth` and `pastYear`. |
| `verbatim` | boolean | Search the exact words, with no spelling fixes. If unset, defaults to `false`. |
| `fileType` | string | Restricts results to files of this type. Accepts one of 11 values, such as `pdf`, `doc` and `docx`. |
| `safeSearch` | boolean | Hide explicit results. If unset, defaults to `false`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 100. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 100. Requests without an API key return the first page only.
