- **Endpoint:** `google.search`
- **Returns:** `data` has `aiOverview`, `knowledgeGraph`, `results`, `peopleAlsoAsk`, `relatedSearches`, `page`.
- **Cost:** 1 credit per call. Failed calls cost nothing.
- **Paging:** Yes. Send `page: 2`, then `3`, until `data.results` is empty. See [Page through results](/guides/paging).

Filter with `time`, `country`, `language`, `fileType` and domains to include or exclude. Without a key there is no paging.
