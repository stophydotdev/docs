## Response

`data.results` lists the products with price and seller, and `filters` lists the choices Google offers to narrow them. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "filters": [
      {
        "group": "Suggested",
        "options": [
          {

  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

Fields to know:

- `filters`: Google's choices for narrowing the search. Send one back as `filter`.
- `price`: Current price in the country's currency.
- `seller`: Store with the listed price.
- `page`: The page number this response holds.
- `position`: Where the result sits in the list, starting at 1.
- `rating`: Star rating, out of 5.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `filter` | A filter from the `filters` of an earlier response. Choices you already picked are applied. Sending a chosen one again removes it. | Text. |
| `country` | Two-letter country code, like `us`. | Two letters. |
| `language` | Two-letter language code, like `en` or `pt`. | Two letters. |
| `page` | Page number, starting at 1. | Whole number, 1 to 20. Default `1`. |

## Cost and limits

- **Price:** 2 credits per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 20.
