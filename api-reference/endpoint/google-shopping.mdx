## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the products with price and seller, and `filters` lists the choices Google offers to narrow them.

The following example is a real response, truncated: each list shows one item and long strings are cut.

| Field | Type | Description |
| --- | --- | --- |
| `filters` | object[] | Google's choices for narrowing the search. Pass one as `filter`. |
| `price` | number | Current price in the country's currency. |
| `seller` | string | Store with the listed price. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `filter` | string | A filter from the `filters` of an earlier response. Previously selected filters remain applied. Passing a selected filter again removes it. |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `language` | string | The language of the results, as a two-letter ISO 639-1 code such as `en`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 20. If unset, defaults to `1`. |

## Billing

Each successful request consumes 2 credits, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 20.
