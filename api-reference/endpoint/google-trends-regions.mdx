Fields to know:

- `values`: Search interest for each query. 100 is the peak.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `us`. | Two letters. |
| `time` | How far back to look. | `pastHour`, `past4Hours`, `pastDay`, `past7Days`, `past30Days`, `past90Days`, `past12Months`, `past5Years` or `since2004`. Default `past12Months`. |
| `searchType` | Where the searches were made. | `web`, `images`, `news`, `shopping` or `youtube`. Default `web`. |
| `category` | Only searches in this category. | One of 25 values, like `artsEntertainment`, `autosVehicles` and `beautyFitness`. |
| `resolution` | How finely to split the results by place. | `country`, `region` or `metro`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
