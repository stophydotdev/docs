## Response

If successful, the response body contains the standard envelope. `data.results[]` contains what is trending, each with its search volume and start time.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "query": "france vs belgium",
        "volume": 100000,
        "increasePercent": 1000,
        "startedAt": "2026-10-05T17:50:00.000Z",
        "isActive": true,
        "related": ["france vs belgium", "france national football team"],
        "categories": ["sports"],
        "trendUrl": "https://trends.google.com/trends/explore?q=france+vs+belgium&geo=US&date=now+1-d"

  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

| Field | Type | Description |
| --- | --- | --- |
| `volume` | number | The search volume of the trend. |
| `increasePercent` | number | The growth in search volume, as a percentage. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. If unset, defaults to `us`. |
| `time` | string | Specifies the time range. Acceptable values are `past4Hours`, `past24Hours`, `past48Hours` and `past7Days`. If unset, defaults to `past24Hours`. |
| `category` | string | Restricts results to trends in this category. Accepts one of 19 values, such as `autos`, `beautyFashion` and `business`. |
| `status` | string | All trends, or only the ones still rising. Acceptable values are `all` and `active`. If unset, defaults to `all`. |
| `sort` | string | Specifies the order of the trends. Acceptable values are `relevance`, `searchVolume`, `recency` and `title`. If unset, defaults to `relevance`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
