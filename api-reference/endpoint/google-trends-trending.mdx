## Response

`data.results` lists what is trending, each with its search volume and start time. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "query": "france vs belgium",
        "volume": 100000,
        "increasePercent": 1000,
        "startedAt": "2026-10-05T17:50:00.000Z",
        "isActive": true,
        "related": ["france vs belgium", "france national football team"],
        "categories": ["sports"],
        "trendUrl": "https://trends.google.com/trends/explore?q=france+vs+belgium&geo=US&date=now+1-d"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `volume`: How many searches the trend has.
- `increasePercent`: How much searches grew, as a percent.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `us`. | Two letters. Default `us`. |
| `time` | How far back to look. | `past4Hours`, `past24Hours`, `past48Hours` or `past7Days`. Default `past24Hours`. |
| `category` | Only trends in this category. | One of 19 values, like `autos`, `beautyFashion` and `business`. |
| `status` | All trends, or only the ones still rising. | `all` or `active`. Default `all`. |
| `sort` | How to order the trends. | `relevance`, `searchVolume`, `recency` or `title`. Default `relevance`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
