## Response

`data.results` lists the videos, each with its site, channel and length. Here is a sample response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "title": "How to bake sourdough bread at home",
        "url": "https://www.example.com/watch?v=abc123",
        "site": "YouTube",
        "channelName": "Example Bakery",
        "durationSeconds": 754,
        "publishedAt": "2026-09-12T00:00:00.000Z",
        "description": "A step by step guide to your first sourdough loaf.",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `site`: Where the video is hosted, like YouTube.
- `publishedAt`: Approximate when Google shows only how long ago, like 1 month ago.
- `page`: The page number this response holds.
- `position`: Where the result sits in the list, starting at 1.
- `durationSeconds`: Length in seconds.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, like `us`. | Two letters. |
| `language` | Two-letter language code, like `en` or `pt`. | Two letters. |
| `includeDomains` | Only results from these domains. | List of text, up to 10. |
| `excludeDomains` | Leave out results from these domains. | List of text, up to 10. |
| `time` | Only results from this period. Leave it out for any time. | `pastHour`, `past24Hours`, `pastWeek`, `pastMonth` or `pastYear`. |
| `duration` | Video length: `short` is under 4 minutes, `medium` is 4 to 20 and `long` is over 20. | `short`, `medium` or `long`. |
| `highQuality` | Only high quality videos. | `true` or `false`. Default `false`. |
| `closedCaptioned` | Only videos with captions. | `true` or `false`. Default `false`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 20. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 20.
