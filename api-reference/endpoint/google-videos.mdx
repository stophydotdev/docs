## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the videos, each with its site, channel and length.

The following example is illustrative.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "title": "How to bake sourdough bread at home",
        "url": "https://www.example.com/watch?v=abc123",
        "site": "YouTube",
        "channelName": "Example Bakery",
        "durationSeconds": 754,
        "publishedAt": "2026-09-12T00:00:00.000Z",
        "description": "A step by step guide to your first sourdough loaf.",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `site` | string | Where the video is hosted, such as YouTube. |
| `publishedAt` | string (ISO 8601) | Approximate when Google shows only how long ago, such as 1 month ago. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |
| `durationSeconds` | integer | The duration, in seconds. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `language` | string | The language of the results, as a two-letter ISO 639-1 code such as `en`. |
| `includeDomains` | string[] | Restricts results to results from these domains. Accepts up to 10 values. |
| `excludeDomains` | string[] | Leave out results from these domains. Accepts up to 10 values. |
| `time` | string | Restricts results to results from this period. Leave it out for any time. Acceptable values are `pastHour`, `past24Hours`, `pastWeek`, `pastMonth` and `pastYear`. |
| `duration` | string | Video length: `short` is under 4 minutes, `medium` is 4 to 20 and `long` is over 20. Acceptable values are `short`, `medium` and `long`. |
| `highQuality` | boolean | Restricts results to high quality videos. If unset, defaults to `false`. |
| `closedCaptioned` | boolean | Restricts results to videos with captions. If unset, defaults to `false`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 20. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 20.
