## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `location` | string | City, region or postal code, such as Kansas City, MO. |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. Accepts one of 62 values, such as `us`, `gb` and `ca`. If unset, defaults to `us`. |
| `distanceMiles` | integer | The search radius around `location`, in miles. `0` is the exact location only. Acceptable values are `0`, `5`, `10`, `15`, `25`, `35`, `50` and `100`. If unset, defaults to `25`. |
| `datePosted` | string | Restricts results to jobs posted in this period. A relisted job keeps its first `publishedAt` and shows the new date in `indexedAt`. Acceptable values are `last24Hours`, `last3Days`, `last7Days` and `last14Days`. |
| `remote` | string | Restricts results to remote or hybrid jobs. Acceptable values are `remote` and `hybrid`. |
| `jobType` | string | Restricts results to this type of job. Acceptable values are `fullTime`, `partTime`, `contract`, `temporary` and `internship`. |
| `experienceLevel` | string | Restricts results to jobs for this level. Acceptable values are `noExperience`, `entry`, `mid` and `senior`. |
| `education` | string | Restricts results to jobs that ask for this education. Acceptable values are `highSchool`, `associate`, `bachelor` and `master`. |
| `sort` | string | Specifies the order of the jobs. Acceptable values are `relevance` and `newest`. If unset, defaults to `relevance`. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
