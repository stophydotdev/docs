## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. | Text. |
| `location` | City, region or postal code, like Kansas City, MO. | Text. |
| `country` | Two-letter country code, like `us`. | One of 62 values, like `us`, `gb` and `ca`. Default `us`. |
| `distanceMiles` | How far from the location to look, in miles. `0` is the exact location only. | `0`, `5`, `10`, `15`, `25`, `35`, `50` or `100`. Default `25`. |
| `datePosted` | Only jobs posted in this period. A relisted job keeps its first `publishedAt` and shows the new date in `indexedAt`. | `last24Hours`, `last3Days`, `last7Days` or `last14Days`. |
| `remote` | Only remote or hybrid jobs. | `remote` or `hybrid`. |
| `jobType` | Only this type of job. | `fullTime`, `partTime`, `contract`, `temporary` or `internship`. |
| `experienceLevel` | Only jobs for this level. | `noExperience`, `entry`, `mid` or `senior`. |
| `education` | Only jobs that ask for this education. | `highSchool`, `associate`, `bachelor` or `master`. |
| `sort` | How to order the jobs. | `relevance` or `newest`. Default `relevance`. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
