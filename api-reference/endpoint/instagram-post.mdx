Fields to know:

- `type`: What the row is: `photo`, `video`, `reel` or `carousel`.
- `publishedAt`: When it was published, as a UTC time.
- `likes`: How many likes.

A comment's reply count can be missing here. Send that comment's id to [Instagram comments](/api-reference/endpoint/instagram-comments) to get the real count and the replies.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
