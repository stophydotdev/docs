- **Endpoint:** `instagram.profile`
- **Returns:** `data` has `userId`, `username`, `userUrl`, `name`, `bio`, `bioLinkUrls`, `pronouns`, `isVerified`, `isPrivate`, `followers`, `following`, `posts`, `avatarUrl`, `postsAnalyzed`, `averageLikes`, `averageComments`, `engagementRate`, `postsPerWeek`, `lastPostAt`, `results`.
- **Cost:** 2 credits per call. Failed calls cost nothing.
- **Paging:** Yes. Send the `cursor` from the response to get the next page. See [Page through results](/guides/paging).

`posts` is the profile's post count. Its latest posts come back in `results`. Page with `limit` and `cursor`.
