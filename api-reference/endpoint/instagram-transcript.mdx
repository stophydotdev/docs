## Response

`data` has what the video says as one block of `text`. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "videoId": "DdG4RIxIPyf",
    "videoUrl": "https://www.instagram.com/p/DdG4RIxIPyf/",
    "language": "en",
    "isAutoGenerated": true,
    "durationSeconds": 72.584118272,
    "transcribedSeconds": 73,
    "text": "Welcome to Africa. Welcome to Earth's wild home. See a new side to animals you know and meet some you've never seen…"
  },
  "creditsUsed": 10,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `text`: The whole transcript as one block.
- `transcribedSeconds`: Seconds of audio that were transcribed when the video had no captions. The price depends on it.
- `isAutoGenerated`: True when the captions were generated, not written by a person.
- `durationSeconds`: Length in seconds.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `language` | Language code, like `en` or `pt-BR`. | Text. |
| `includeTimestamps` | Return each line with its start and end time, in `segments`. | `true` or `false`. Default `false`. |

## Cost and limits

- **Price:** 1 credit when the video has captions; otherwise 2 credits plus 1 credit for every 10 seconds of audio, up to 30 minutes. A call costs 182 credits at most. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
