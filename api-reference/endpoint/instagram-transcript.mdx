## Response

If successful, the response body contains the standard envelope. `data` contains what the video says as one block of `text`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "videoId": "DdG4RIxIPyf",
    "videoUrl": "https://www.instagram.com/p/DdG4RIxIPyf/",
    "language": "en",
    "isAutoGenerated": true,
    "durationSeconds": 72.584118272,
    "transcribedSeconds": 73,
    "text": "Welcome to Africa. Welcome to Earth's wild home. See a new side to animals you know and meet some you've never seen…"
  },
  "creditsUsed": 10,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `text` | string | The whole transcript as one block. |
| `transcribedSeconds` | number | Seconds of audio that were transcribed when the video had no captions. The price depends on it. |
| `isAutoGenerated` | boolean | `true` if the captions were generated, not written by a person. |
| `durationSeconds` | number | The duration, in seconds. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | The language of the results, as a BCP 47 tag such as `en` or `pt-BR`. |
| `includeTimestamps` | boolean | Return each line with its start and end time, in `segments`. If unset, defaults to `false`. |

## Billing

A successful request consumes 2 credits plus 1 credit for every 10 seconds of audio, up to 30 minutes, up to 182 credits. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
