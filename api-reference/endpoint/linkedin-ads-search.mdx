## Response

`data.results` lists the ads, each with its advertiser, text and images. Here is a real response, shortened: lists show one row and long text is cut.

Fields to know:

- `cursor`: Send it back as `cursor` to get the next page. The last page has none.
- `total`: How many results match in all, not only on this page.

Run dates, impressions and who paid show only in [LinkedIn ad details](/api-reference/endpoint/linkedin-ads-ad), and only for ads shown in the EU. Pass an EU country to get them.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. | Text. |
| `advertiser` | Only ads from this advertiser. | Text. |
| `country` | Two-letter country code, like `us`. | Two letters. |
| `within` | How recent the ads are. | `month`, `year` or `all`. Default `all`. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
