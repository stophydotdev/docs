Returns a company's profile, size and industry. The company is identified by its URL or ID.

## Request

Exactly one of `companyUrl` or `companyId` is required. A request that sets both, or none, fails with `invalidRequest`.

## Response

If successful, the response body contains the standard envelope. `data` contains the company's industry, size, headquarters, website and description.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "companyId": "microsoft",
    "companyUrl": "https://www.linkedin.com/company/microsoft",
    "name": "Microsoft",
    "industry": "Software Development",
    "size": "10,001+ employees",
    "employees": 231728,
    "headquarters": "Redmond, Washington",
    "website": "https://news.microsoft.com/",
    "followers": 29232105,
    "description": "Every company has a mission. What's ours? To empower every person and every organization to achieve more. We believe…",
    "specialties": ["Business Software"]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `size` | string | The size band LinkedIn shows for the company. |
| `employees` | integer | The employee count LinkedIn shows. |

For every field, see the response schema on this page.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
