Fields to know:

- `page`: The page number this response holds.
- `publishedAt`: When it was published, as a UTC time.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. | Text. |
| `location` | The city or area to search in. | Text. |
| `datePosted` | Only jobs posted in this period. | `anyTime`, `pastMonth`, `pastWeek` or `past24Hours`. Default `anyTime`. |
| `company` | One company, or up to five. Use LinkedIn links, slugs like `google`, or company ids. | Text, or a list of 1 to 5. |
| `easyApply` | Only Easy Apply jobs. | `true` or `false`. Default `false`. |
| `fewApplicants` | Only jobs with fewer than 10 applicants. | `true` or `false`. Default `false`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 100. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 100.
