If successful, the response body contains the standard envelope. `data.results[]` contains the jobs, each with its company, location and posting date.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `location` | string | The city or area to search in. |
| `datePosted` | string | Restricts results to jobs posted in this period. Acceptable values are `anyTime`, `pastMonth`, `pastWeek` and `past24Hours`. If unset, defaults to `anyTime`. |
| `company` | object | One company, or up to five. Use LinkedIn links, slugs such as `google`, or company ids. Accepts a string or an array of 1 to 5 strings. |
| `easyApply` | boolean | Restricts results to Easy Apply jobs. If unset, defaults to `false`. |
| `fewApplicants` | boolean | Restricts results to jobs with fewer than 10 applicants. If unset, defaults to `false`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 100. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 100.
