Returns a person's or company's latest public posts. The profile is identified by its URL, ID, URL or ID.

## Request

Exactly one of `profileUrl`, `profileId`, `companyUrl` or `companyId` is required. A request that sets more than one, or none, fails with `invalidRequest`.

## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the latest public posts, each with its text, likes and date.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "postId": "7509276499837902849",
        "postUrl": "https://www.linkedin.com/posts/satyanadella_the-motivation-behind-the-new-copilot-intelligence-activity-750927649983790…",
        "text": "The motivation behind the new Copilot: intelligence is accelerating fast. Now we need to diffuse it everywhere.",
        "publishedAt": "2026-09-25T15:43:53.171Z",
        "likes": 959,
        "authorName": "Satya Nadella",
        "authorUrl": "https://www.linkedin.com/in/satyanadella"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `likes` | integer | The number of likes. |

For every field, see the response schema on this page.

<Note>Returns the most recent public posts that LinkedIn displays for the page, including reposts. This is typically at most 10 posts. Older posts are not available, and this method is not paginated.</Note>

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
