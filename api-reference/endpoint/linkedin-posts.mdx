## Response

`data.results` lists the latest public posts, each with its text, likes and date. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "postId": "7509276499837902849",
        "postUrl": "https://www.linkedin.com/posts/satyanadella_the-motivation-behind-the-new-copilot-intelligence-activity-750927649983790…",
        "text": "The motivation behind the new Copilot: intelligence is accelerating fast. Now we need to diffuse it everywhere.",
        "publishedAt": "2026-09-25T15:43:53.171Z",
        "likes": 959,
        "authorName": "Satya Nadella",
        "authorUrl": "https://www.linkedin.com/in/satyanadella"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `publishedAt`: When it was published, as a UTC time.
- `likes`: How many likes.

It returns the latest public posts LinkedIn shows for the page, reposts included. That is usually up to 10. Older posts are not available, and there is no cursor.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
