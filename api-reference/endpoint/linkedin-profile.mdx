## Response

`data` has the person's headline, location, about text, roles and education. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "profileId": "satyanadella",
    "profileUrl": "https://www.linkedin.com/in/satyanadella",
    "name": "Satya Nadella",
    "headline": "Chairman and CEO at Microsoft",
    "location": "Redmond, Washington, United States",
    "about": "As chairman and CEO of Microsoft, I define my mission and that of my company as empowering every person and every organ…",
    "followers": 12205170,
    "roles": [
      {
        "title": "Chairman and CEO",
        "companyName": "Microsoft",
        "companyUrl": "https://www.linkedin.com/company/microsoft",
        "from": "Feb 2014",
        "isCurrent": true
      }
    ],
    "education": [
      {
        "school": "The University of Chicago Booth School of Business",
        "schoolUrl": "https://www.linkedin.com/school/universityofchicagoboothschoolofbusiness",
        "from": "1994",
        "to": "1996"
      }
    ]
  },
  "creditsUsed": 2,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `roles`: The person's jobs. `isCurrent` marks the current one.

## Cost and limits

- **Price:** 2 credits per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
