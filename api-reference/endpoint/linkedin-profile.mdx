## Response

If successful, the response body contains the standard envelope. `data` contains the person's headline, location, about text, roles and education.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "profileId": "satyanadella",
    "profileUrl": "https://www.linkedin.com/in/satyanadella",
    "name": "Satya Nadella",
    "headline": "Chairman and CEO at Microsoft",
    "location": "Redmond, Washington, United States",
    "about": "As chairman and CEO of Microsoft, I define my mission and that of my company as empowering every person and every…",
    "followers": 12205170,
    "roles": [
      {
        "title": "Chairman and CEO",

      {
        "school": "The University of Chicago Booth School of Business",
        "schoolUrl": "https://www.linkedin.com/school/universityofchicagoboothschoolofbusiness",

  },
```

| Field | Type | Description |
| --- | --- | --- |
| `roles` | object[] | The person's jobs. `isCurrent` marks the current one. |

For every field, see the response schema on this page.

## Billing

Each successful request consumes 2 credits, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
