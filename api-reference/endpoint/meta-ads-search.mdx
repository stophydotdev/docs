- **Endpoint:** `meta.ads.search`
- **Returns:** `data` has `results`.
- **Cost:** 1 credit per call. Failed calls cost nothing.
- **Paging:** Yes. Send the `cursor` from the response to get the next page. See [Page through results](/guides/paging).

`mediaType` keeps image, video, text, meme or image-and-meme ads. `platforms`, `language`, `shownFrom` and `shownTo` use the Ad Library's own filters.
