## Options

| Option | What it does | Values |
| --- | --- | --- |
| `country` | Two-letter country code, or `all`. | Text. Default `us`. |
| `status` | Active ads, inactive ads or both. | `active`, `inactive` or `all`. Default `active`. |
| `mediaType` | Only ads of this type. `text` means no image or video. | `image`, `video`, `text`, `meme` or `imageAndMeme`. |
| `platforms` | Only ads shown on at least one of these platforms. | List of `facebook`, `instagram`, `audienceNetwork`, `messenger`, `whatsapp` or `threads`. |
| `language` | Only ads written in this language. Two-letter code, like `en`. | Two letters. |
| `shownFrom` | Only ads shown on or after this day. | Date, `YYYY-MM-DD`. |
| `shownTo` | Only ads shown on or before this day. | Date, `YYYY-MM-DD`. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
