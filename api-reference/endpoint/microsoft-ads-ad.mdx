## Response

`data` has the ad's text, dates, impressions, countries and targeting. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "adId": "71056095591684",
    "advertiserId": "4295034605",
    "advertiserName": "Amazon Europe Core S.à r.l",
    "headline": "Shop for cushion walk shoes at Amazon - Great Selection of cushion walk shoes",
    "text": "Buy affordable shoes & bags from top brands. Free returns on eligible items",
    "linkUrl": "https://www.amazon.co.uk/s/?ie=UTF8&keywords=cushion+walk+shoes&index=aps",
    "linkCaption": "www.amazon.co.uk/Fashion/Accessories",
    "paidBy": "Amazon Europe Core S.à r.l",
    "firstShownAt": "2023-06-01T00:00:00.000Z",
    "lastShownAt": "2026-09-28T00:00:00.000Z",
    "impressionsMin": 1000,
    "impressionsMax": 2500,
    "countries": [
      {
        "country": "Austria",
        "share": 0.3
      }
    ],
    "targeting": [
      {
        "type": "Location",
        "isExcluded": false
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `firstShownAt`: The first day the ad was shown.
- `lastShownAt`: The last day the ad was shown.
- `impressionsMin`: With `impressionsMax`, the range for how many times the ad was shown.
- `paidBy`: Who paid for the ad.
- `countries`: The countries where the ad was shown.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
