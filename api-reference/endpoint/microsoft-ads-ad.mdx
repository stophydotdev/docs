## Response

If successful, the response body contains the standard envelope. `data` contains the ad's text, dates, impressions, countries and targeting.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "adId": "71056095591684",
    "advertiserId": "4295034605",
    "advertiserName": "Amazon Europe Core S.à r.l",
    "headline": "Shop for cushion walk shoes at Amazon - Great Selection of cushion walk shoes",
    "text": "Buy affordable shoes & bags from top brands. Free returns on eligible items",
    "linkUrl": "https://www.amazon.co.uk/s/?ie=UTF8&keywords=cushion+walk+shoes&index=aps",
    "linkCaption": "www.amazon.co.uk/Fashion/Accessories",
    "paidBy": "Amazon Europe Core S.à r.l",
    "firstShownAt": "2023-06-01T00:00:00.000Z",
    "lastShownAt": "2026-09-28T00:00:00.000Z",
    "impressionsMin": 1000,
    "impressionsMax": 2500,
    "countries": [
      {
        "country": "Austria",
        "share": 0.3
      }
    ],
    "targeting": [
      {
        "type": "Location",
        "isExcluded": false
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `firstShownAt` | string (ISO 8601) | The first day the ad was shown. |
| `lastShownAt` | string (ISO 8601) | The last day the ad was shown. |
| `impressionsMin` | integer | With `impressionsMax`, the range for the number of times the ad was shown. |
| `paidBy` | string | The entity that paid for the ad. |
| `countries` | object[] | The countries in which the ad was shown. |

For every field, see the response schema on this page.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
