## Response

`data.results` lists the advertisers that match. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "advertiserId": "4295000966",
        "advertiserName": "Nike - EMEA",
        "advertiserCountry": "Netherlands",
        "isVerified": true
      }
    ],
    "total": 18
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `total`: How many results match in all, not only on this page.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
