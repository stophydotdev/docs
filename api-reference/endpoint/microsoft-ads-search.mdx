## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the ads, each with its advertiser, headline and text.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "adId": "71056095591684",
        "advertiserId": "4295034605",
```

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | The pagination token. Pass it as `cursor` to retrieve the next page. Omitted on the last page. |
| `total` | integer | The total number of matching results, across all pages. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `advertiser` | string | An advertiser id from Microsoft ads advertisers. |
| `country` | string | Two-letter code of an EU or EEA country, such as `de`. Microsoft publishes ads for these countries only. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
