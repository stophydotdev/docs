## Response

`data.results` lists the ads, each with its advertiser, headline and text. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "adId": "71056095591684",
        "advertiserId": "4295034605",
        "advertiserName": "Amazon Europe Core S.à r.l",
        "headline": "Shop for cushion walk shoes at Amazon - Great Selection of cushion walk shoes",
        "text": "Buy affordable shoes & bags from top brands. Free returns on eligible items",
        "linkUrl": "https://www.amazon.co.uk/s/?ie=UTF8&keywords=cushion+walk+shoes&index=aps",
        "linkCaption": "www.amazon.co.uk/Fashion/Accessories"
      }
    ],
    "total": 1000,
    "cursor": "24"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `cursor`: Send it back as `cursor` to get the next page. The last page has none.
- `total`: How many results match in all, not only on this page.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. | Text. |
| `advertiser` | An advertiser id from Microsoft ads advertisers. | Text. |
| `country` | Two-letter code of an EU or EEA country, like `de`. Microsoft publishes ads for these countries only. | Two letters. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
