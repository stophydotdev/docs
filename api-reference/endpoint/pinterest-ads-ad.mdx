## Response

`data` has the ad's text, dates, reach and audience. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "adId": "4593179166442157824",
    "adUrl": "https://ads.pinterest.com/ads-repository/4593179166442157824/",
    "headline": "Das Mädchen vom Moorhof",
    "text": "Schweden, um 1900: Die Magd Helga erwartet ein Kind. Die junge Häuslerin hat auf einem Hof im Värmland gearbeitet, der …",
    "advertisers": ["Thalia Bücher GmbH"],
    "imageUrl": "https://i.pinimg.com/474x/62/b8/37/62b837bc76a44632ce732e03b88b8d50.jpg",
    "firstShownAt": "2026-02-18T00:00:00.000Z",
    "lastShownAt": "2026-10-02T00:00:00.000Z",
    "reachMin": 0,
    "reachMax": 10000,
    "reachByCountry": [
      {
        "country": "Germany",
        "reachMin": 0,
        "reachMax": 10000
      }
    ],
    "countries": ["Germany"],
    "ageRanges": ["18+"],
    "genders": ["UNSPECIFIED"],
    "audienceTypes": ["VISITOR"],
    "isCommercial": true
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `firstShownAt`: The first day the ad was shown.
- `lastShownAt`: The last day the ad was shown.
- `reachMin`: With `reachMax`, the range for how many people the ad reached.
- `countries`: The countries where the ad was shown.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
