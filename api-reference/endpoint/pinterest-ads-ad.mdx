## Response

If successful, the response body contains the standard envelope. `data` contains the ad's text, dates, reach and audience.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "adId": "4593179166442157824",
    "adUrl": "https://ads.pinterest.com/ads-repository/4593179166442157824/",
    "headline": "Das Mädchen vom Moorhof",
    "text": "Schweden, um 1900: Die Magd Helga erwartet ein Kind. Die junge Häuslerin hat auf einem Hof im Värmland gearbeitet, der…",
    "advertisers": ["Thalia Bücher GmbH"],
    "imageUrl": "https://i.pinimg.com/474x/62/b8/37/62b837bc76a44632ce732e03b88b8d50.jpg",
    "firstShownAt": "2026-02-18T00:00:00.000Z",
    "lastShownAt": "2026-10-02T00:00:00.000Z",
    "reachMin": 0,
    "reachMax": 10000,
    "reachByCountry": [
      {
        "country": "Germany",
        "reachMin": 0,
        "reachMax": 10000
      }
    ],
    "countries": ["Germany"],
    "ageRanges": ["18+"],
    "genders": ["UNSPECIFIED"],
    "audienceTypes": ["VISITOR"],
    "isCommercial": true
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `firstShownAt` | string (ISO 8601) | The first day the ad was shown. |
| `lastShownAt` | string (ISO 8601) | The last day the ad was shown. |
| `reachMin` | integer | With `reachMax`, the range for the number of people the ad reached. |
| `countries` | string[] | The countries in which the ad was shown. |

For every field, see the response schema on this page.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
