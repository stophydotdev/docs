## Response

`data.results` lists the ads, each with its dates, reach and audience. Here is a real response, shortened: lists show one row and long text is cut.

Fields to know:

- `cursor`: Send it back as `cursor` to get the next page. The last page has none.
- `firstShownAt`: The first day the ad was shown.
- `lastShownAt`: The last day the ad was shown.
- `reachMin`: With `reachMax`, the range for how many people the ad reached.
- `countries`: The countries where the ad was shown.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `advertiser` | Only ads from this advertiser. Results do not name the advertiser. | Text. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

It takes `country` and `advertiser`, not a keyword.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
