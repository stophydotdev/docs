## Response

If successful, the response body contains the standard envelope. `data` contains the profile's bio, followers and post count.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "userId": "28829152388",
    "username": "nasa",
    "userUrl": "https://www.threads.com/@nasa",
    "name": "NASA",
    "bio": "Making the seemingly impossible, possible. ✨",
    "isVerified": true,
    "isPrivate": false,
    "followers": 12764861,
    "threads": 144,

  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
```

<Note>followers is exact. threads is the count Threads shows, which it rounds above 1,000 (1.6K comes back as 1600).</Note>

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
