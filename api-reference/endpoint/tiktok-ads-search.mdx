## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the ads, each with its advertiser and how many people it reached.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `advertiser` | string | Restricts results to ads from this advertiser name. |
| `country` | string | Two-letter code of a European country, such as `de`. TikTok shows ads for these countries only. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
