- **Endpoint:** `tiktok.profile`
- **Returns:** `data` has `userId`, `username`, `userUrl`, `name`, `bio`, `bioLinkUrl`, `avatarUrl`, `isVerified`, `isPrivate`, `isOrganization`, `language`, `createdAt`, `followers`, `following`, `likes`, `videos`, `results`.
- **Cost:** 1 credit per call. Failed calls cost nothing.
- **Paging:** Yes. Send the `cursor` from the response to get the next page. See [Page through results](/guides/paging).

The profile's videos come back in `results`. Page with `cursor`.
