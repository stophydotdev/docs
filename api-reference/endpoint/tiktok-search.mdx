## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `type` | string | Videos or users. Acceptable values are `videos` and `users`. If unset, defaults to `videos`. |
| `sort` | string | Specifies the order of videos. Leave it out for relevance. Acceptable values are `relevance`, `mostLiked` and `datePosted`. |
| `datePosted` | string | Restricts results to videos from this period. Leave it out for all time. Acceptable values are `past24Hours`, `thisWeek`, `thisMonth`, `last3Months` and `last6Months`. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
