Returns a product's price, stock, seller, images and videos. The product is identified by its URL or ID.

## Request

Exactly one of `productUrl` or `productId` is required. A request that sets both, or none, fails with `invalidRequest`.

## Response

If successful, the response body contains the standard envelope. `data` contains the product's price, stock, seller and images.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
