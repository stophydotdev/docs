## Response

`data` has the product's rating, and `results` lists the first page of its reviews. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "rating": 4,
    "reviews": 2956,
    "results": [
      {
        "reviewId": "7689658813176153870",
        "rating": 1,
        "text": "It said it was supposed to be crunchy it was not crunchy and didn’t taste good",
        "authorName": "f**s",
        "isVerified": true,
        "publishedAt": "2026-09-26T02:04:41.569Z",
        "country": "US",
        "imageUrls": ["https://p16-oec-general-useast5.ttcdn-us.com/tos-useast5-i-omjb5zjo8w-tx/ca205418263841dba0067240a5eea513~tplv-fhlh96ny…", "https://p16-oec-general-useast5.ttcdn-us.com/tos-useast5-i-omjb5zjo8w-tx/12ce5ce9ab5142a78b0a816658f3705c~tplv-fhlh96ny…"]
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `publishedAt`: When it was published, as a UTC time.
- `rating`: Star rating, out of 5.
- `reviews`: How many reviews the rating is based on.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
