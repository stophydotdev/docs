Returns what a TikTok video says, from captions or its own audio. The video is identified by its URL or ID.

## Request

Exactly one of `videoUrl` or `videoId` is required. A request that sets both, or none, fails with `invalidRequest`.

## Response

If successful, the response body contains the standard envelope. `data` contains what the video says as one block of `text`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "videoId": "7137423965982592302",
    "videoUrl": "https://www.tiktok.com/@charlidamelio/video/7137423965982592302",
    "language": "en",
    "isAutoGenerated": true,
    "durationSeconds": 11.12093696,
    "transcribedSeconds": 12,
    "text": "First time, first time, first time, look, you'll hear your eyes. What are you willing to do? All I tell you what…"
  },
  "creditsUsed": 4,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `text` | string | The whole transcript as one block. |
| `transcribedSeconds` | number | Seconds of audio that were transcribed when the video had no captions. The price depends on it. |
| `isAutoGenerated` | boolean | `true` if the captions were generated, not written by a person. |
| `durationSeconds` | number | The duration, in seconds. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | The language of the results, as a BCP 47 tag such as `en` or `pt-BR`. |
| `includeTimestamps` | boolean | Return each line with its start and end time, in `segments`. If unset, defaults to `false`. |

<Note>Videos longer than 3 minutes are rejected with `invalidRequest`. Rejected requests are not billed.</Note>

## Billing

A successful request consumes 1 credit when the video has captions; otherwise 2 credits plus 1 credit for every 10 seconds of audio, up to 3 minutes, up to 20 credits. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
