- **Endpoint:** `transcript`
- **Returns:** `data` has `videoId`, `videoUrl`, `language`, `isAutoGenerated`, `durationSeconds`, `text`, `segments`.
- **Cost:** 2 credits per call. Failed calls cost nothing.
- **Paging:** No.

Pass a YouTube, TikTok or Instagram link in `video`. Set `includeTimestamps` to get each line with its time. TikTok videos over 3 minutes are refused, and refused calls cost nothing.
