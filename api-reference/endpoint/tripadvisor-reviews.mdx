## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | The language of the reviews, or `all`. If unset, defaults to `en`. |
| `ratings` | integer[] | Restricts results to reviews with these star ratings, from 1 to 5. Accepts up to 5 values. |
| `travelerTypes` | string[] | Restricts results to reviews from these travelers. Acceptable values are `families`, `couples`, `solo`, `business` and `friends`. Accepts up to 5 values. |
| `months` | string[] | Restricts results to reviews written in these months of the year. Acceptable values are `marMay`, `junAug`, `sepNov` and `decFeb`. Accepts up to 4 values. |
| `sort` | string | `mostRecent` puts the newest first. `detailed` orders by recency and by how much a review says. Acceptable values are `mostRecent` and `detailed`. If unset, defaults to `mostRecent`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 500. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 500.
