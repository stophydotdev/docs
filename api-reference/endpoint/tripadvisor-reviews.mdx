Fields to know:

- `page`: The page number this response holds.
- `total`: How many results match in all, not only on this page.
- `rating`: Star rating, out of 5.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `language` | The language of the reviews, or `all`. | Text. Default `en`. |
| `ratings` | Only reviews with these star ratings, from 1 to 5. | List of whole numbers, up to 5. |
| `travelerTypes` | Only reviews from these travelers. | List of `families`, `couples`, `solo`, `business` or `friends`, up to 5. |
| `months` | Only reviews written in these months of the year. | List of `marMay`, `junAug`, `sepNov` or `decFeb`, up to 4. |
| `sort` | `mostRecent` puts the newest first. `detailed` orders by recency and by how much a review says. | `mostRecent` or `detailed`. Default `mostRecent`. |
| `page` | Page number, starting at 1. | Whole number, 1 to 500. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 500.
