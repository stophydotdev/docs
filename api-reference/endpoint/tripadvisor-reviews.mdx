- **Endpoint:** `tripadvisor.reviews`
- **Returns:** `data` has `placeId`, `placeName`, `placeType`, `placeUrl`, `total`, `results`, `page`.
- **Cost:** 1 credit per call. Failed calls cost nothing.
- **Paging:** Yes. Send `page: 2`, then `3`, until `data.results` is empty. See [Page through results](/guides/paging).

Narrow the reviews with `ratings`, `travelerTypes` and `months`, and order them with `sort`.
