## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the places, each with its type, address and link.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "placeId": "187591",
        "placeUrl": "https://www.tripadvisor.com/Hotel_Review-g186338-d187591-Reviews-The_Ritz_London_Hotel-London_England.html",
        "name": "The Ritz London Hotel",
        "type": "accommodation",
        "address": "150 Piccadilly",

  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
```

| Field | Type | Description |
| --- | --- | --- |
| `type` | string | The kind of place. |
| `placeUrl` | string (URL) | A token. Pass it as `placeUrl` to retrieve the place's details or reviews. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `type` | string | The kind of place. Acceptable values are `all`, `hotels`, `restaurants`, `attractions` and `geos`. If unset, defaults to `all`. |
| `location` | string | Narrow the search to this place. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
