## Response

`data.results` lists the places, each with its type, address and link. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "placeId": "187591",
        "placeUrl": "https://www.tripadvisor.com/Hotel_Review-g186338-d187591-Reviews-The_Ritz_London_Hotel-London_England.html",
        "name": "The Ritz London Hotel",
        "type": "accommodation",
        "address": "150 Piccadilly",
        "parent": "London, England",
        "latitude": 51.507088,
        "longitude": -0.141628,
        "imageUrl": "https://dynamic-media-cdn.tripadvisor.com/media/photo-o/33/be/ef/d4/the-ritz-london-entrance.jpg?w=1200&h=900&s=1"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `type`: The kind of place.
- `placeUrl`: Send it as `placeUrl` to get the place's details or reviews.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `type` | The kind of place. | `all`, `hotels`, `restaurants`, `attractions` or `geos`. Default `all`. |
| `location` | Narrow the search to this place. | Text. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
