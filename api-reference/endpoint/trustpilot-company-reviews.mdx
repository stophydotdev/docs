## Response

If successful, the response body contains the standard envelope. `data.results[]` contains a page of the company's reviews, each with its rating, title, text and date.

The following example is a real response, truncated: each list shows one item and long strings are cut.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `ratings` | integer[] | Restricts results to reviews with these star ratings, 1 to 5. Empty means every rating. Accepts up to 5 values. |
| `language` | string | Restricts results to reviews in this language, as a two-letter code such as `en`. Defaults to `all`. If unset, defaults to `all`. |
| `datePublished` | string | Restricts results to reviews published in the last 30 days, 3, 6 or 12 months. Acceptable values are `last30Days`, `last3Months`, `last6Months` and `last12Months`. |
| `verifiedOnly` | boolean | Restricts results to reviews Trustpilot marks as verified. If unset, defaults to `false`. |
| `search` | string | Restricts results to reviews that mention this word or phrase. |
| `page` | integer | Page number, starting at 1. Trustpilot shows 10 pages of 20 reviews without an account; narrow with ratings, language, `datePublished` or search to reach older reviews. Must be between 1 and 10. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 10.
