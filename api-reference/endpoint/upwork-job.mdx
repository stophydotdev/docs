## Response

`data` has the job's description, budget and skills, and what the job page shows about the client. Here is a sample response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "jobId": "~021234567890123456789",
    "jobUrl": "https://www.upwork.com/jobs/~021234567890123456789",
    "title": "React developer for a dashboard",
    "description": "We need a React developer to build a reporting dashboard.",
    "skills": ["React", "TypeScript"],
    "type": "hourly",
    "experienceLevel": "intermediate",
    "workload": "partTime",
    "duration": "oneToThreeMonths",
    "hourlyRateMin": 30,
    "hourlyRateMax": 60,
    "publishedAt": "2026-10-05T09:30:00.000Z",
    "applicants": 12,
    "hired": 0,
    "interviewing": 2,
    "invitesSent": 3,
    "positions": 1,
    "clientCountry": "United States",
    "clientTotalSpent": 18000,
    "clientHires": 24,
    "clientReviews": 18,
    "clientRating": 4.9
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `type`: Whether the job pays by the hour (`hourly`) or a fixed price (`fixed`).
- `workload`: Upwork's hours needed. Empty when the job does not say, including fixed-price jobs and clients who are not sure.
- `duration`: Upwork's project length. `underOneMonth` is under one month, `oneToThreeMonths` is one to three months, `threeToSixMonths` is three to six months, and `overSixMonths` is longer.
- `clientTotalSpent`: How much the client has spent in all.
- `publishedAt`: When it was published, as a UTC time.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
