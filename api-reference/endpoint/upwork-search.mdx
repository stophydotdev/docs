## Response

`data.results` lists the jobs, each with its budget or hourly rate, skills and posting date. Here is a sample response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "jobId": "~021234567890123456789",
        "jobUrl": "https://www.upwork.com/jobs/~021234567890123456789",
        "title": "React developer for a dashboard",
        "description": "We need a React developer to build a reporting dashboard.",
        "skills": ["React", "TypeScript"],
        "type": "hourly",
        "experienceLevel": "intermediate",
        "workload": "partTime",
        "duration": "oneToThreeMonths",
        "hourlyRateMin": 30,
        "hourlyRateMax": 60,
        "publishedAt": "2026-10-05T09:30:00.000Z"
      }
    ],
    "total": 1250,
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `type`: Whether the job pays by the hour (`hourly`) or a fixed price (`fixed`).
- `workload`: Upwork's hours needed. Empty when the job does not say, including fixed-price jobs and clients who are not sure.
- `duration`: Upwork's project length. `underOneMonth` is under one month, `oneToThreeMonths` is one to three months, `threeToSixMonths` is three to six months, and `overSixMonths` is longer.
- `page`: The page number this response holds.
- `total`: How many results match in all, not only on this page.
- `publishedAt`: When it was published, as a UTC time.

Hours needed, project length and hourly rate apply to hourly jobs only.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `query` | Words to search for. | Text. |
| `sort` | How to order the jobs. | `newest` or `relevance`. Default `newest`. |
| `jobType` | Hourly jobs or fixed-price jobs. | `hourly` or `fixed`. |
| `experienceLevel` | Only jobs that ask for this level. | `entry`, `intermediate` or `expert`. |
| `workload` | Hours needed: full time, part time or as needed. Only hourly jobs say this, so the search stays hourly. | `fullTime`, `partTime` or `asNeeded`. |
| `duration` | Project length: under one month, one to three months, three to six months or over six months. Only hourly jobs say this, so the search stays hourly. | `underOneMonth`, `oneToThreeMonths`, `threeToSixMonths` or `overSixMonths`. |
| `minHourlyRate` | Lowest hourly rate in USD. A job matches when its posted range overlaps this minimum, so 25 to 50 matches a minimum of 50. The search stays hourly. | Whole number, 1 to 999. |
| `maxHourlyRate` | Highest hourly rate in USD. Send it with `minHourlyRate`. The job's posted range overlaps both, and the search stays hourly. | Whole number, 1 to 999. |
| `page` | Page number, starting at 1. | Whole number, 1 to 100. Default `1`. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 100.
