## Response

If successful, the response body contains the standard envelope. `data` contains the batch's progress and credits used when it stopped.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "id": "job_BC0vf8IzmDUA4VeGy9M7tA",
    "status": "completed",
    "total": 2,
    "completed": 2,
    "failed": 0,
    "creditsUsed": 2
  },
  "creditsUsed": 0,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `total` | integer | The total number of matching results, across all pages. |

## Billing

Each successful request consumes 0 credits, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
