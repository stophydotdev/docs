## Response

If successful, the response body contains the standard envelope. `data` contains `url`, `emails`, `phones` and `socials`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "url": "https://plausible.io/",
    "emails": [
      {
        "email": "name@example.com",
        "pages": ["https://plausible.io/contact"]
      }
    ],
    "socials": [
      {
        "network": "x",
        "username": "PlausibleHQ",
        "url": "https://x.com/PlausibleHQ",
        "pages": ["https://plausible.io/", "https://plausible.io/contact"]
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

<Note>Reads the page you send and the contact, imprint and about pages it links to. Use [Web web Scrape](/api-reference/endpoint/web-scrape) to read a page in full.</Note>

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
