## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the images, each with its size, thumbnail and the page it is on.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `safeSearch` | boolean | Hide explicit images. If unset, defaults to `false`. |
| `limit` | integer | The maximum number of images to return. Billed at 1 credit per 10 returned. Must be between 1 and 100. If unset, defaults to `10`. |

## Billing

A successful request consumes 1 credit per 10 images, up to 10 credits. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
