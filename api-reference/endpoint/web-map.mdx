## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the site's pages, each with its address and title.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "url": "https://bun.com/docs/runtime/sqlite",
        "title": "SQLite | Bun Docs"
      }
    ],
    "page": 1,
    "totalPages": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `totalPages` | integer | The number of pages that match the request. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `search` | string | Keep only addresses that mention these words, best matches first, such as pricing. |
| `includeSubdomains` | boolean | Also list pages on subdomains, such as docs.bun.com for bun.com. If unset, defaults to `false`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 100. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 100.
