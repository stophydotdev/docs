If successful, the response body contains the standard envelope. `data` contains `results`.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `time` | string | Restricts results to articles from the past week, month or year. Leave out for any time. Acceptable values are `pastWeek`, `pastMonth` and `pastYear`. |
| `limit` | integer | The maximum number of articles to return. Billed at 1 credit per 10 returned. Must be between 1 and 50. If unset, defaults to `10`. |

## Billing

A successful request consumes 1 credit per 10 articles, up to 5 credits. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
