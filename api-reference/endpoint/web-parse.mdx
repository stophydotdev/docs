## Response

If successful, the response body contains the standard envelope. `data` contains the file's text as markdown, with its metadata.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "markdown": "# How tides work\n\nThe Moon pulls on the oceans and makes two bulges of water that move around the Earth as it turns,…",
    "isTruncated": false,
    "metadata": {
      "title": "How tides work",
      "contentType": "text/html"
    }
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

<Note>To read a page or a PDF by its address, use [Web web Scrape](/api-reference/endpoint/web-scrape).</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `filename` | string | The file's name, such as report.docx. The type is read from the file itself. |
| `maxPages` | integer | Read at most this many PDF pages, sheets or slides; `isTruncated` says when the file had more. Must be between 1 and 100. If unset, defaults to `100`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
