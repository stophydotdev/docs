## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the pages, each with its title and description, and its text when `scrapeResults` is on.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "url": "https://www.paymoapp.com/blog/project-management-software/",
        "title": "20+ Best Project Management Software for 2026 • Paymo",
        "description": "3 weeks ago - Jira – best for software engineers & programmers · ProjectManager – a complex PM software geared towards…",
        "position": 1
      }
    ]
  },
  "creditsUsed": 2,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
```

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | The country to query, as a two-letter ISO 3166-1 code such as `us`. |
| `includeDomains` | string[] | Restricts results to results from these domains. Accepts up to 10 values. |
| `excludeDomains` | string[] | Leave out results from these domains. Accepts up to 10 values. |
| `time` | string | Restricts results to pages from the past week, month or year. Leave out for any time. Acceptable values are `pastWeek`, `pastMonth` and `pastYear`. |
| `safeSearch` | boolean | Hide explicit results. If unset, defaults to `false`. |
| `limit` | integer | The maximum number of results to return. Billed at 1 credit per 10 returned. Must be between 1 and 100. If unset, defaults to `10`. |
| `scrapeResults` | boolean | Also read the top results and add each page's text as markdown. Costs 1 more credit for each result that comes back with its text. If unset, defaults to `false`. |
| `scrapeLimit` | integer | The number of of the top results to read when `scrapeResults` is on. Must be between 1 and 5. If unset, defaults to `3`. |

## Billing

A successful request consumes 1 credit per 10 results, plus 1 credit for each result that comes back with its page text when scrapeResults is on, up to 15 credits. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
