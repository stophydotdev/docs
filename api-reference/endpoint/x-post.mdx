Scrape an X post. The post is identified by its URL or ID.

## Request

Exactly one of `postUrl` or `postId` is required. A request that sets both, or none, fails with `invalidRequest`.

<Note>This endpoint can be called without an API key, subject to per-address limits. Pagination requires a key.</Note>

## Response

If successful, the response body contains the standard envelope. `data` contains the post's text and author, and its exact likes, replies, reposts, quotes, bookmarks and views.

The following example is a real response, truncated: each list shows one item and long strings are cut.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
