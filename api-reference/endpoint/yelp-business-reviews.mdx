## Response

If successful, the response body contains the standard envelope. `data` contains `businessId`, `businessName`, `businessUrl`, `total`, `results` and `page`.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `sort` | string | relevance (Yelp Sort), newest, oldest, highest (Highest Rated) or lowest (Lowest Rated), the same as Yelp's own Sort menu. Acceptable values are `relevance`, `newest`, `oldest`, `highest` and `lowest`. If unset, defaults to `relevance`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 250. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 250.
