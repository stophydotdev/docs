## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the businesses, each with its rating, price level, categories and address.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "businessId": "TVHztfQAJUIaJDgdJuke-g",
        "businessAlias": "blue-dragon-plumbing-austin-2",
        "businessUrl": "https://www.yelp.com/biz/blue-dragon-plumbing-austin-2",
        "name": "Blue Dragon Plumbing",
        "rating": 4.9,
        "reviews": 532,
        "categories": ["Plumbing"],
        "addressCity": "Austin"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |

For every field, see the response schema on this page.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
