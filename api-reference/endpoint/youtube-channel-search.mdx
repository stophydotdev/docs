Searches one channel's videos, equivalent to the search box on its YouTube page. The channel is identified by its URL or ID.

## Request

`query` is required. Exactly one of `channelUrl` or `channelId` is required. A request that sets both, or none, fails with `invalidRequest`.

## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the channel's videos that match the query.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
