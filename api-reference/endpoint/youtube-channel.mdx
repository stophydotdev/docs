Fields to know:

- `cursor`: Send it back as `cursor` to get the next page. The last page has none.
- `type`: What the row is: `video`, `playlist` or `post`.
- `videos`: How many videos the channel has.
- `publishedAt`: Approximate: YouTube lists show only how long ago a video was published. [YouTube video](/api-reference/endpoint/youtube-video) has the exact time.
- `durationSeconds`: Length in seconds.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `tab` | Which tab of the channel to read. `releases` are a music channel's albums. | `videos`, `shorts`, `live`, `playlists`, `podcasts`, `releases` or `posts`. Default `videos`. |
| `sort` | How to order the items on the videos, shorts and live tabs. | `latest`, `popular` or `oldest`. Default `latest`. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none. A cursor lasts 6 hours. After that, start again from the first page.
