- **Endpoint:** `youtube.channel`
- **Returns:** `data` has `channelId`, `channelUrl`, `channelName`, `channelUsername`, `description`, `subscribers`, `videos`, `avatarUrl`, `bannerUrl`, `country`, `joinedDate`, `totalViews`, `results`.
- **Cost:** 1 credit per call. Failed calls cost nothing.
- **Paging:** Yes. Send the `cursor` from the response to get the next page. See [Page through results](/guides/paging).
