## Request

Exactly one of `channelUrl` or `channelId` is required. A request that sets both, or none, fails with `invalidRequest`.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `tab` | string | Specifies which tab of the channel to read. `releases` are a music channel's albums. Acceptable values are `videos`, `shorts`, `live`, `playlists`, `podcasts`, `releases` and `posts`. If unset, defaults to `videos`. |
| `sort` | string | Specifies the order of the items on the videos, shorts and live tabs. Acceptable values are `latest`, `popular` and `oldest`. If unset, defaults to `latest`. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page. A cursor expires 6 hours after it is issued.
