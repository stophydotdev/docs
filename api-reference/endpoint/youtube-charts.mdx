## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the chart entries in order, each with its position.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json

  "success": true,
  "data": {
    "chart": "topSongs",
    "country": "us",
    "throughDate": "2026-10-01",
```

| Field | Type | Description |
| --- | --- | --- |
| `throughDate` | string (date) | The last day the chart covers. |
| `periodsOnChart` | integer | Weeks on the chart, or days for a daily chart. |
| `position` | integer | The 1-based position of the result in the list. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `chart` | string | Specifies which chart to read. Acceptable values are `topSongs`, `topVideos`, `topArtists`, `topShortsSongs`, `topPodcasts` and `trending`. If unset, defaults to `topSongs`. |
| `country` | string | Two-letter country code, or `global`. If unset, defaults to `us`. |
| `interval` | string | `daily` is only available for `topVideos` and `topShortsSongs`. Acceptable values are `weekly` and `daily`. If unset, defaults to `weekly`. |
| `limit` | integer | The maximum number of results to return. Billed at 1 credit per 10 returned. Must be between 1 and 100. |

## Billing

A successful request consumes 1 credit per 10 results, up to 10 credits. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
