## Response

`data.results` lists the chart entries in order, each with its position. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "chart": "topSongs",
    "country": "us",
    "throughDate": "2026-10-01",
    "results": [
      {
        "position": 1,
        "periodsOnChart": 1,
        "title": "Patient Zero",
        "artists": ["Taylor Swift"],
        "views": 7084018,
        "videoId": "BpR280fXISA",
        "videoUrl": "https://www.youtube.com/watch?v=BpR280fXISA",
        "releaseDate": "2026-09-25",
        "label": "Taylor Swift"
      }
    ]
  },
  "creditsUsed": 10,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `throughDate`: The last day the chart covers.
- `periodsOnChart`: Weeks on the chart, or days for a daily chart.
- `position`: Where the result sits in the list, starting at 1.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `chart` | Which chart to read. | `topSongs`, `topVideos`, `topArtists`, `topShortsSongs`, `topPodcasts` or `trending`. Default `topSongs`. |
| `country` | Two-letter country code, or `global`. | Text. Default `us`. |
| `interval` | `daily` is only available for `topVideos` and `topShortsSongs`. | `weekly` or `daily`. Default `weekly`. |
| `limit` | Return at most this many results. You pay 1 credit per 10 returned. | Whole number, 1 to 100. |

## Cost and limits

- **Price:** 1 credit per 10 results. A call costs 10 credits at most. Failed calls and empty results cost nothing. Send `limit` to get fewer results and pay for fewer.
- **Paging:** None. One call returns everything for the input.
