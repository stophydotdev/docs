## Response

`data.results` lists the videos on the hashtag page. Here is a real response, shortened: lists show one row and long text is cut.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "type": "video",
        "videoId": "NGF2WGKX5dU",
        "videoUrl": "https://www.youtube.com/watch?v=NGF2WGKX5dU",
        "title": "The Complete Sourdough Starter Guide",
        "channelId": "UCepVey5oiinAQGgT06r-h5A",
        "channelName": "Mary's Nest",
        "channelUrl": "https://www.youtube.com/channel/UCepVey5oiinAQGgT06r-h5A",
        "channelUsername": "MarysNest",
        "durationSeconds": 1840,
        "views": 688100,
        "thumbnailUrl": "https://i.ytimg.com/vi/NGF2WGKX5dU/hqdefault.jpg",
        "isShort": false,
        "isLive": false,
        "publishedAt": "2019-10-06T04:02:42.000Z"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

Fields to know:

- `type`: What the row is: `video`.
- `publishedAt`: Approximate: YouTube lists show only how long ago a video was published. [YouTube video](/api-reference/endpoint/youtube-video) has the exact time.
- `durationSeconds`: Length in seconds.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
