## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `type` | string | Leave out for videos, channels and playlists. Use shorts for Shorts. Acceptable values are `videos`, `shorts`, `channels`, `playlists` and `movies`. |
| `duration` | string | Restricts results to videos of this length. Acceptable values are `under3Minutes`, `3to20Minutes` and `over20Minutes`. |
| `uploadDate` | string | Restricts results to videos uploaded in this period. Acceptable values are `today`, `thisWeek`, `thisMonth` and `thisYear`. |
| `features` | string[] | Restricts results to videos with these features. Accepts one of 11 values, such as `360`, `live` and `4k`. Accepts up to 11 values. |
| `prioritize` | string | Specifies how results are ranked. Acceptable values are `relevance` and `popularity`. If unset, defaults to `relevance`. |
| `cursor` | string | The pagination token from the previous response. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, pass the value of `data.cursor` as `cursor` in a subsequent request. A response that omits `cursor` is the last page.
