Fields to know:

- `cursor`: Send it back as `cursor` to get the next page. The last page has none.
- `type`: What the row is: `video`, `channel` or `playlist`.
- `publishedAt`: Approximate: YouTube lists show only how long ago a video was published. [YouTube video](/api-reference/endpoint/youtube-video) has the exact time.
- `durationSeconds`: Length in seconds.
- `videos`: How many videos there are.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `type` | Leave out for videos, channels and playlists. Use shorts for Shorts. | `videos`, `shorts`, `channels`, `playlists` or `movies`. |
| `duration` | Only videos of this length. | `under3Minutes`, `3to20Minutes` or `over20Minutes`. |
| `uploadDate` | Only videos uploaded in this period. | `today`, `thisWeek`, `thisMonth` or `thisYear`. |
| `features` | Only videos with these features. | List of One of 11 values, like `360`, `live` and `4k`, up to 11. |
| `prioritize` | What to put first. | `relevance` or `popularity`. Default `relevance`. |
| `cursor` | The `cursor` from the previous response. Send it back unchanged. | Text from the previous response. |

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** Send the `cursor` from the response to get the next page, until a response has none.
