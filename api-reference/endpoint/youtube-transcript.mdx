- **Returns:** `data` has `id`, `url`, `language`, `isAutoGenerated`, `durationSeconds`, `text`, `segments`.
- **Cost:** 3 credits. Failed calls cost nothing. Calls without a key are free.
- **Without a key:** Yes, within the [free limits](/without-a-key).
- **Paging:** No.

Pass a video id or URL in `video`. Set `includeTimestamps` to get each line with its time.
