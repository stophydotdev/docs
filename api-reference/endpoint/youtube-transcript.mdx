- **Endpoint:** `youtube.transcript`
- **Returns:** `data` has `videoId`, `videoUrl`, `language`, `isAutoGenerated`, `durationSeconds`, `transcribedSeconds`, `text`, `segments`.
- **Cost:** 1 credit per call. Failed calls cost nothing.
- **Paging:** No.

Send `videoUrl` or `videoId`, not both. Set `includeTimestamps` to get each line with its time.
