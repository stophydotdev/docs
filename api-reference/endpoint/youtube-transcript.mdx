Returns what a YouTube video says, from its captions. The video is identified by its URL or ID.

## Request

Exactly one of `videoUrl` or `videoId` is required. A request that sets both, or none, fails with `invalidRequest`.

<Note>This endpoint can be called without an API key, subject to per-address limits. Pagination requires a key.</Note>

## Response

If successful, the response body contains the standard envelope. `data` contains what the video says as one block of `text`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "videoId": "p0fybvFyOlM",
    "videoUrl": "https://www.youtube.com/watch?v=p0fybvFyOlM",
    "language": "ar",
    "isAutoGenerated": true,
    "durationSeconds": 799,
    "text": "يا للهول. شيء جديد على وشك الحدوث. حسناً، سنرى شيئاً جديداً قادماً من OpenAI. هذا صحيح. سنحصل على شيء مذهل. وهل تعرف…"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `text` | string | The whole transcript as one block. |
| `isAutoGenerated` | boolean | `true` if YouTube wrote the captions, not a person. |
| `language` | string | The language of the transcript. |
| `durationSeconds` | number | The duration, in seconds. |

For every field, see the response schema on this page.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | The language of the results, as a BCP 47 tag such as `en` or `pt-BR`. |
| `includeTimestamps` | boolean | Return each line with its start and end time, in `segments`. If unset, defaults to `false`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
