Returns a video's stats, description, chapters and most replayed moments. The video is identified by its URL or ID.

## Request

Exactly one of `videoUrl` or `videoId` is required. A request that sets both, or none, fails with `invalidRequest`.

<Note>This endpoint can be called without an API key, subject to per-address limits. Pagination requires a key.</Note>

## Response

If successful, the response body contains the standard envelope. `data` contains the video's title, channel, stats, description and tags, plus chapters and most replayed moments when it has them.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "videoId": "p0fybvFyOlM",
    "videoUrl": "https://www.youtube.com/watch?v=p0fybvFyOlM",

    "channelId": "UCUyeluBRhGPCW4rPe_UvBZQ",
    "channelName": "The PrimeTime",
```

| Field | Type | Description |
| --- | --- | --- |
| `publishedAt` | string (ISO 8601) | When the video was published. |
| `durationSeconds` | integer | The duration, in seconds. |
| `likes` | integer | The number of likes. |

For every field, see the response schema on this page.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
