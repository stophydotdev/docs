## Response

`data` has the video's title, channel, stats, description and tags, plus chapters and most replayed moments when it has them. Here is a real response, shortened: lists show one row and long text is cut.

Fields to know:

- `publishedAt`: When the video was published.
- `durationSeconds`: Length in seconds.
- `likes`: How many likes.

## Cost and limits

- **Price:** 1 credit per call. Failed calls and empty results cost nothing.
- **Paging:** None. One call returns everything for the input.
