## Response

If successful, the response body contains the standard envelope. `data` contains the home's price, address, size, description, photos and facts.

| Field | Type | Description |

| `price` | number | Asking price, monthly rent, or the sale price of a sold home. Omitted when Zillow shows none, such as for sold homes in states that keep sale prices private. |

## Billing

Each successful request consumes 2 credits, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
