## Response

`data.results` lists the homes, each with its price, address, size and status. Here is a real response, shortened: lists show one row and long text is cut.

Fields to know:

- `price`: Asking price, monthly rent, or the sale price of a sold home. Left out when Zillow shows none, such as for sold homes in states that keep sale prices private.
- `page`: The page number this response holds.
- `totalPages`: How many pages match.
- `total`: How many results match in all, not only on this page.
- `statusText`: Zillow's own label for the listing, like Active.
- `daysOnZillow`: Days since the home was listed.

## Options

| Option | What it does | Values |
| --- | --- | --- |
| `status` | Homes for sale, for rent or sold. | `forSale`, `forRent` or `sold`. Default `forSale`. |
| `minPrice` | Lowest price. | Number, 0 or more. |
| `maxPrice` | Highest price. | Number, 0 or more. |
| `minBedrooms` | Fewest bedrooms. | Whole number, 0 to 20. |
| `maxBedrooms` | Most bedrooms. | Whole number, 0 to 20. |
| `minBathrooms` | Fewest bathrooms. | Number, 0 to 20. |
| `minSqft` | Smallest size, in square feet. | Whole number, 0 or more. |
| `maxSqft` | Largest size, in square feet. | Whole number, 0 or more. |
| `minLotSize` | Smallest lot, in square feet. | Whole number, 0 or more. |
| `maxLotSize` | Largest lot, in square feet. | Whole number, 0 or more. |
| `minYearBuilt` | Only homes built in or after this year. | Whole number, 1600 to 2100. |
| `maxYearBuilt` | Only homes built in or before this year. | Whole number, 1600 to 2100. |
| `maxHoa` | Highest monthly HOA fee, in USD. `0` means no HOA fee. | Number, 0 or more. |
| `minParkingSpots` | Only homes with at least this many parking spots. | Whole number, 1 to 4. |
| `daysOnZillow` | Only homes listed in the last 1, 7, 14, 30 or 90 days, or 6, 12, 24 or 36 months. For sold homes, it means sold in that time. | `1Day`, `7Days`, `14Days`, `30Days`, `90Days`, `6Months`, `12Months`, `24Months` or `36Months`. |
| `hasPool` | Only homes with a pool. | `true` or `false`. Default `false`. |
| `hasGarage` | Only homes with a garage. | `true` or `false`. Default `false`. |
| `hasAirConditioning` | Only homes with air conditioning. | `true` or `false`. Default `false`. |
| `isWaterfront` | Only waterfront homes. | `true` or `false`. Default `false`. |
| `singleStory` | Only single-story homes. | `true` or `false`. Default `false`. |
| `openHouse` | Only homes with an open house. | `true` or `false`. Default `false`. |
| `priceReduced` | Only homes with a price cut. | `true` or `false`. Default `false`. |
| `has3dTour` | Only homes with a 3D tour. | `true` or `false`. Default `false`. |
| `petsAllowed` | Only places that allow pets. Rentals only: set `status` to `forRent`. | `true` or `false`. Default `false`. |
| `homeTypes` | Only these kinds of home. | List of `house`, `townhouse`, `multiFamily`, `condo`, `land`, `apartment` or `manufactured`. |
| `sort` | How to order the homes. | `relevance`, `newest`, `priceHigh`, `priceLow`, `bedrooms`, `bathrooms`, `squareFeet` or `lotSize`. Default `relevance`. |
| `keywords` | Words the listing must mention, like "pool" or "fixer upper". | Text. |
| `page` | Page number, starting at 1. | Whole number, 1 to 20. Default `1`. |

## Cost and limits

- **Price:** 2 credits per call. Failed calls and empty results cost nothing.
- **Paging:** Send `page: 2`, then `3` and on, until `data.results` is empty. Page numbers go up to 20.
