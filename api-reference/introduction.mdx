Stophy is a web scraping API for AI agents. Every endpoint is a `POST` to the same base URL with a JSON body. No key needed for this one.

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

You get Google results back with `creditsUsed: 0`. The path is `/v1/` plus the endpoint id with dots as slashes, so `youtube.transcript` is `/v1/youtube/transcript`. A field the endpoint does not take returns `400`.

## Base URL

```text
https://api.stophy.dev
```

## Authentication

Create a key in the [dashboard](https://stophy.dev/signup). Send it with every request:

```text
Authorization: Bearer <key>
```

<CodeGroup>

```bash cURL icon="terminal"
curl -X POST https://api.stophy.dev/v1/reddit/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

```ts TypeScript icon="/images/icons/typescript.svg"
const response = await fetch("https://api.stophy.dev/v1/reddit/search", {
  method: "POST",
  headers: {
    authorization: "Bearer " + process.env.STOPHY_API_KEY,
    "content-type": "application/json",
  },
  body: JSON.stringify({ query: "bun runtime" }),
});
```

```python Python icon="python"
import os
import requests

response = requests.post(
    "https://api.stophy.dev/v1/reddit/search",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={"query": "bun runtime"},
    timeout=30,
)
```

</CodeGroup>

A missing or invalid key on an endpoint that needs one returns `401` with code `unauthorized`. The endpoints marked `keyless: true` in the [catalog](https://api.stophy.dev/v1/endpoints) work without a key, with [rate limits](/rate-limits).

## Responses

A successful call returns `success`, `data`, `creditsUsed` and `requestId`.

```json
{
  "success": true,
  "data": {
    "results": [{ "title": "Bun", "url": "https://bun.com/", "position": 1 }]
  },
  "creditsUsed": 1,
  "requestId": "7db121ac-d8e6-479a-b17c-59e3fe5fabd8"
}
```

`data` is one object. A list comes back in `data.results`, with `data.cursor` when another page exists. A value that belongs to a related resource carries that resource in its name, such as `videoId`, `videoUrl`, `channelName` and `placeId`. Empty values are left out.

A failed call returns an error status and `{ "success": false, "error": { ... } }`. See [Errors](/api-reference/errors).

## One call, one page, one price

Each call returns one page. Most calls cost 1 credit and a few cost 2. A few are priced by what comes back, such as long lists and transcripts. A call that fails or finds nothing costs nothing. See [Credits and billing](/billing).

Some endpoints take `page`, some take `cursor`, and the rest return everything in one call. See [Page through results](/guides/paging).

## Send a link or an id

To point at one thing, send its link or its id, never both. That is `videoUrl` or `videoId`, `placeUrl` or `placeId`, `userUrl` or `username`, and so on. Each endpoint's page lists the pair. Sending both, or neither, returns a `400`.
