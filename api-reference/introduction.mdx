## Base URL

```text
https://api.stophy.dev
```

Data endpoints use `POST /v1/<source>/<endpoint>` with a JSON object body. Unknown input fields return `400`.

## Authentication

Create a key in the [dashboard](https://stophy.dev/signup). Send it with every request:

```text
Authorization: Bearer <key>
```

<CodeGroup>

```bash cURL icon="terminal"
curl -X POST https://api.stophy.dev/v1/reddit/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

```ts TypeScript icon="/images/icons/typescript.svg"
const response = await fetch("https://api.stophy.dev/v1/reddit/search", {
  method: "POST",
  headers: {
    authorization: "Bearer " + process.env.STOPHY_API_KEY,
    "content-type": "application/json",
  },
  body: JSON.stringify({ query: "bun runtime" }),
});
```

```python Python icon="python"
import os
import requests

response = requests.post(
    "https://api.stophy.dev/v1/reddit/search",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={"query": "bun runtime"},
    timeout=30,
)
```

</CodeGroup>

An invalid or missing key returns `401` with code `unauthorized`.

## Response envelope

A successful call returns `success`, `data`, `creditsUsed`, and `requestId`:

```json
{
  "success": true,
  "data": {},
  "creditsUsed": 1,
  "requestId": "7db121ac-d8e6-479a-b17c-59e3fe5fabd8"
}
```

The shape of `data` depends on the endpoint. A failed call returns an error status and `{ "success": false, "error": { ... } }`. See [Errors](/api-reference/errors).

## Markdown output

Send `Accept: text/markdown` with your key to get readable text instead of JSON. Errors remain JSON. See the [advanced guide](/advanced-guide#markdown-output).
