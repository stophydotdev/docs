See what your key has spent credits on. Needs an API key, and the call is free.

```bash
curl "https://api.stophy.dev/v1/logs?days=7&page=0&endpoint=google.search" \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```

You get your recent paid calls, 50 per page, newest first. Only paid calls are logged.

<ParamField query="days" type="integer" default="7">
  How many days back to look, from 1 to 90.
</ParamField>

<ParamField query="page" type="integer" default="0">
  The page to return, from 0. Past the last page you get an empty `logs` list.
</ParamField>

<ParamField query="endpoint" type="string">
  Only calls to this endpoint id, such as `google.search`.
</ParamField>

<ParamField query="apiKeyId" type="string">
  Only calls made with this API key.
</ParamField>

<ResponseField name="logs" type="object[]" required>
  The calls on this page.
  <Expandable title="properties">
    <ResponseField name="id" type="string">The log entry ID.</ResponseField>
    <ResponseField name="requestId" type="string">The `requestId` the call returned.</ResponseField>
    <ResponseField name="createdAt" type="string">When the call was made, as an ISO 8601 time.</ResponseField>
    <ResponseField name="endpoint" type="string">The endpoint id, such as `google.search`.</ResponseField>
    <ResponseField name="credits" type="integer">Credits the call used.</ResponseField>
    <ResponseField name="apiKeyId" type="string | null">The API key used.</ResponseField>
    <ResponseField name="apiKeyName" type="string | null">That key's name.</ResponseField>
    <ResponseField name="method" type="string">Always `POST`.</ResponseField>
    <ResponseField name="status" type="integer">Always `200`.</ResponseField>
    <ResponseField name="response" type="string">Always `success`.</ResponseField>
    <ResponseField name="durationMs" type="integer | null">Always `null`.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="endpoints" type="string[]" required>
  Every endpoint id, for building a filter.
</ResponseField>

<ResponseField name="page" type="integer" required>The page returned.</ResponseField>
<ResponseField name="pageSize" type="integer" required>Calls per page: 50.</ResponseField>
<ResponseField name="total" type="integer" required>Calls that match, across all pages.</ResponseField>
<ResponseField name="totalPages" type="integer" required>How many pages there are.</ResponseField>

<RequestExample>
```bash cURL icon="terminal"
curl "https://api.stophy.dev/v1/logs?days=7&page=0&endpoint=google.search" \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
</RequestExample>
