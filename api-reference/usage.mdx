Returns your current balance and totals for every call you have paid for. Needs an API key. Free.

<ResponseField name="balanceMicros" type="integer" required>
  Your balance in micros. `1500` is one credit.
</ResponseField>

<ResponseField name="creditsUsed" type="integer" required>
  Credits used by all your calls so far.
</ResponseField>

<ResponseField name="requestCount" type="integer" required>
  How many paid calls you have made.
</ResponseField>

<RequestExample>
```bash cURL icon="terminal"
curl https://api.stophy.dev/v1/usage \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "balanceMicros": 0,
  "creditsUsed": 0,
  "requestCount": 0
}
```
</ResponseExample>

This response is not wrapped in `success` and `data`. Without a valid key it answers `401` with code `unauthorized`.
