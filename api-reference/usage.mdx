Check your balance and totals. Needs an API key, and the call is free.

```bash
curl https://api.stophy.dev/v1/usage \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```

<ResponseField name="balanceMicros" type="integer" required>
  Your balance in millionths of a dollar. One credit is `1500`, so divide by 1,500 to get credits.
</ResponseField>

<ResponseField name="creditsUsed" type="integer" required>
  Credits used by all your calls so far.
</ResponseField>

<ResponseField name="requestCount" type="integer" required>
  How many paid calls you have made.
</ResponseField>

<RequestExample>
```bash cURL icon="terminal"
curl https://api.stophy.dev/v1/usage \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "balanceMicros": 1200000,
  "creditsUsed": 300,
  "requestCount": 120
}
```
</ResponseExample>

This response is not wrapped in `success` and `data`. Without a valid key it returns `401` with code `unauthorized`.
