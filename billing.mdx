Stophy uses credits. You buy credits ahead of time and each successful call uses some.

## Price

| You add | Price per 1,000 credits |
| --- | --- |
| Less than $100 | $1.50 |
| $100 or more | $1.20 |
| $500 or more | $0.80 |

- New accounts start with 1,000 free credits.
- Top up at [stophy.dev](https://stophy.dev). The smallest top-up is $10.
- Credits never expire.

## What a call costs

Every endpoint has one flat price per call, from 1 to 5 credits. The price does not change with how many results come back. `limit` (1 to 100) returns fewer results at the same price. Errors and empty results cost nothing.

| Cost | Endpoints |
| --- | --- |
| 5 credits | `googletravel.flights`, `ads.search`, `ads.ad`, `meta.ads.page` |
| 3 credits | `maps.search`, `airbnb.search`, `zillow.search`, `rightmove.search`, `immoscout.search`, `upwork.search`, `linkedin.jobs.search` |
| 2 credits | `transcript`, `instagram.profile`, `zillow.property` |
| 1 credit | Everything else, including every Reddit endpoint and `ads.advertisers` |

One call returns one page. To get the next page, send the `cursor` from the response in a new call, which costs the same again and continues with no gaps. Find an endpoint's cost in the [API reference](/api-reference/introduction), on each source page, or in `credits` in `GET https://api.stophy.dev/v1/endpoints`.

Failed calls cost nothing. A call that Stophy refuses, for example a TikTok video over 3 minutes sent to `transcript`, costs nothing either.

## See what a call cost

Every successful response tells you:

- `creditsUsed` in the JSON body
- the `x-credits-used` header

For your balance and history, use [`GET /v1/usage`](/api-reference/usage) and [`GET /v1/logs`](/api-reference/logs).

## Running out

When your balance is too low for a call, it answers `402` with code `insufficientCredits` and nothing is charged. The error says how many credits the call needs and how many you have. Top up and try again.
