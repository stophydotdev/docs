---
title: "Errors and retries"
description: "What each error means and when to retry."
---

A failed call answers with an HTTP error status and this body:

```json
{
  "success": false,
  "error": {
    "code": "rateLimited",
    "message": "Too many requests. Retry after the number of seconds in Retry-After.",
    "retryable": true,
    "retryAfterSeconds": 12,
    "requestId": "..."
  }
}
```

- Retry only when `retryable` is `true`.
- When `retryAfterSeconds` or the `Retry-After` header is present, wait that long first. Otherwise back off, for example 0.5 s, then 1 s, then 2 s.
- Failed calls cost nothing.
- Include `requestId` when you contact support.

## Error codes

| Code | Status | Retryable | What it means |
| --- | --- | --- | --- |
| `invalidRequest` | 400 | No | The input is not valid, or the source rejected a value you sent. The message says which field. |
| `unauthorized` | 401 | No | The API key is missing or not valid. |
| `insufficientCredits` | 402 | No | Your balance is too low for this call. Top up at [stophy.dev](https://stophy.dev). |
| `forbidden` | 403 | No | This request is not allowed. |
| `notFound` | 404 | No | The endpoint or the thing you asked for does not exist. |
| `unsupportedMediaType` | 415 | No | Send the body as JSON with `content-type: application/json`. |
| `rateLimited` | 429 | Yes | Too many requests, or the free limit without a key is used up. Wait for `Retry-After`. |
| `tooManyInFlight` | 429 | Yes | Too many of your calls are running at once. Wait for one to finish. |
| `internalError` | 500 or 503 | Yes | Something went wrong on our side. Try again shortly. |
| `sourceChanged` | 502 | No | The source answered in a shape we could not read. Retrying will not help yet. |
| `sourceUnavailable` | 503 | Yes | The source is not answering right now. Try again in a few seconds. |
| `sourceRefused` | 503 | Yes | The source is refusing requests right now. Try again in a few minutes. |
| `sourceTimeout` | 504 | Yes | The source took too long to answer. Try again. |

## A retry loop

<CodeGroup>

```ts TypeScript
async function call(path: string, input: unknown, attempts = 3) {
  for (let attempt = 0; ; attempt++) {
    const response = await fetch(`https://api.stophy.dev${path}`, {
      method: "POST",
      headers: {
        authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
        "content-type": "application/json",
      },
      body: JSON.stringify(input),
    });
    const body = await response.json();
    if (body.success) return body.data;
    if (!body.error.retryable || attempt + 1 >= attempts) throw new Error(body.error.message);
    const seconds = body.error.retryAfterSeconds ?? 0.5 * 2 ** attempt;
    await new Promise((resolve) => setTimeout(resolve, seconds * 1000));
  }
}
```

```python Python
import os
import time
import httpx

def call(path, payload, attempts=3):
    for attempt in range(attempts):
        response = httpx.post(
            f"https://api.stophy.dev{path}",
            headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
            json=payload,
            timeout=30,
        )
        body = response.json()
        if body["success"]:
            return body["data"]
        error = body["error"]
        if not error["retryable"] or attempt + 1 >= attempts:
            raise RuntimeError(error["message"])
        time.sleep(error.get("retryAfterSeconds", 0.5 * 2**attempt))
```
