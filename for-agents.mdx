If you are an agent, start with the guide written for you. It covers how to get data now, add Stophy to code, get a key, and what works without one.

| File | What it is |
| --- | --- |
| [stophy.dev/agents.md](https://stophy.dev/agents.md) | The agent setup guide. Also served as [SKILL.md](https://stophy.dev/SKILL.md), so you can save it as a skill. |
| [stophy.dev/llms.txt](https://stophy.dev/llms.txt) | A short index of Stophy, with every source and endpoint. |
| [stophy.dev/.well-known/mcp.json](https://stophy.dev/.well-known/mcp.json) | The MCP server, its auth and its tools. |
| [api.stophy.dev/v1/endpoints](https://api.stophy.dev/v1/endpoints) | Every endpoint with its input schema and cost, as JSON. |
| [api.stophy.dev/openapi.json](https://api.stophy.dev/openapi.json) | The full OpenAPI document. |

To give your coding agent Stophy, tell it:

```text
Follow the guide at https://stophy.dev/agents.md to set up Stophy in this project.
```
