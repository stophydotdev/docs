One call returns one page. Endpoints that page take a `cursor` input. Each endpoint page in the [API reference](/api-reference/introduction) says whether it pages.

## How it works

1. Send your input as usual.
2. If `data.cursor` is in the response, send the same input again with that `cursor`.
3. Stop when a response has no `cursor`. You have everything.

Keep the rest of the input the same between pages. Each page is a normal call and costs its normal price, from 1 to 5 credits, like any other call.

## Loop through every page

<CodeGroup>

```ts Node.js
const results = [];
let cursor: string | undefined;
do {
  const response = await fetch("https://api.stophy.dev/v1/youtube/search", {
    method: "POST",
    headers: {
      authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
      "content-type": "application/json",
    },
    body: JSON.stringify({ query: "rust tutorial", cursor }),
  });
  const { data } = await response.json();
  results.push(...data.results);
  cursor = data.cursor;
} while (cursor && results.length < 100);
```

```python Python
import os
import requests

results = []
cursor = None
while True:
    body = {"query": "rust tutorial"}
    if cursor:
        body["cursor"] = cursor
    response = requests.post(
        "https://api.stophy.dev/v1/youtube/search",
        headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
        json=body,
        timeout=30,
    )
    data = response.json()["data"]
    results += data["results"]
    cursor = data.get("cursor")
    if not cursor or len(results) >= 100:
        break
```

</CodeGroup>

Set your own stop, like the 100 results above. Some sources have many pages.

## Keep fewer results with limit

Every endpoint that returns `results` takes `limit`, from 1 to 100. It keeps at most that many results from the page. The price stays the same, and the `cursor` still points to the next page.

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime","limit":2}'
```

Use it to keep a model's context small. It does not fetch more: a page holds what the source returns for one call.
