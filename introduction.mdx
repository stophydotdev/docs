Stophy gives your agent or app structured public web data from one API: search results, video, social posts, places, products, jobs, ads, and prices. Every call returns one flat JSON object at a fixed price.

## Make your first request

Web search works without a key, so you can run this as it is:

```bash
curl -X POST https://api.stophy.dev/v1/web/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime","limit":2}'
```

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "title": "Bun — A fast all-in-one JavaScript runtime",
        "url": "https://bun.com/",
        "description": "Bundle, install, and run JavaScript & TypeScript — all in Bun.",
        "domain": "bun.com",
        "position": 1
      }
    ]
  },
  "creditsUsed": 0,
  "requestId": "0094bdbc-2935-4184-8df9-f476e561a522"
}
```

Stophy has 100 endpoints across 35 sources. See [what you can get](/sources/web) for the full list, or follow the [quickstart](/quickstart) to get a key and call the rest.
