Stophy gives your agent or app structured public web data from one API: search results, video, social posts, places, jobs, shopping, apps, property, ads, and flight prices. Every call returns one flat JSON object at a price you can see before you call, from 1 to 4 credits, except transcripts of videos without captions.

## Make your first request

Google search works without a key, so you can run this as it is:

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

```json
{

  "data": {
    "results": [
```
