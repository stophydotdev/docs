Stophy gives you structured public web data from one API: web search, YouTube, Reddit, TikTok, Instagram, LinkedIn, maps, shopping, jobs, real estate, finance and more.

There are 161 endpoints across 41 sources. Every endpoint takes a JSON body and answers with clean JSON, or with markdown when that is easier to read.

## How it works

Every endpoint is `POST https://api.stophy.dev/v1/<source>/<endpoint>`. The body is the endpoint's input. The response is:

```json
{ "success": true, "data": { ... }, "creditsUsed": 1, "requestId": "..." }
```

You pay in credits, only for calls that succeed. New accounts start with 500 free credits.
