Stophy gives your agent or app structured public web data from one API: search results, video, social posts, places, products, jobs, ads, and prices. Every endpoint returns JSON for your code, or markdown for a model, from the same request.

## Make your first request

```bash
curl -X POST https://api.stophy.dev/v1/reddit/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

Stophy has 161 endpoints across 41 sources. See [what you can get](/sources/web) for the full list, or follow the [quickstart](/quickstart) to get a key and make this call yourself.
