Stophy is the web access layer for AI agents: one interface between your agent and the web's major platforms.

The API exposes search, video, social, maps, commerce, jobs, real estate, apps and ads as endpoints. Each endpoint has a fixed request schema, a fixed price and the same response envelope. Most requests consume 1 credit, some consume 2, and long lists consume 1 credit per 10 results.

## Make your first request

Google search works without a key, so you can run this as it is:

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```
