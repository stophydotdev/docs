Stophy is a web scraping API for AI agents. One API to search the web, read what people say, and look up products, places, jobs and homes. Pay only for answers.

## Try it now

No account, no key. Run this.

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

<Accordion title="Response">
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "type": "web",
        "url": "https://bun.com/",
        "title": "Bun — A fast all-in-one JavaScript runtime",
        "description": "Bun is a fast JavaScript runtime & toolkit. All in one. Runtime, package manager, test runner and bundler in a single binary.",
        "position": 1
      }
    ]
  },
  "creditsUsed": 0,
  "requestId": "5d8fa22c-6ed4-4690-b20f-5b6b92b160a6"
}
```
</Accordion>

You get Google results with `creditsUsed: 0`. A key lifts the free limit, and a failed call costs nothing.

## Connect your agent

<CodeGroup>
```bash Claude Code
claude mcp add --transport http stophy https://api.stophy.dev/mcp
```

```bash Codex
codex mcp add stophy --url https://api.stophy.dev/mcp
```
</CodeGroup>

Your agent can use the free endpoints right away. To use every endpoint, sign in with your browser at `https://mcp.stophy.dev/mcp`. Every other client has its own page in [MCP server](/mcp-server).

## Search, then read

Find posts with `reddit.search`, then open one with `reddit.post` to read its comments. Most sites work this way. Each call returns one page, and the response tells you how to get the next. `reddit.search` is free to try, and `reddit.post` needs a key. See [Page through results](/guides/paging).

## What it costs

- Most calls cost 1 credit.
- New accounts get 1,000 free credits.
- A call that fails or finds nothing costs nothing.

See [Credits and billing](/billing) for the few that cost more.
