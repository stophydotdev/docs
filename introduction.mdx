Stophy gives your agent or app structured public web data from one API. Search the web, read YouTube and Reddit, look up places, products, jobs, homes, ads and prices. There are 161 endpoints across 41 sources. Each one takes a JSON body and answers with clean JSON, or with markdown when you want text a model can read.

## How a call looks

```bash
curl -X POST https://api.stophy.dev/v1/web/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime","limit":2}'
```

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "title": "Bun — A fast all-in-one JavaScript runtime",
        "url": "https://bun.com/",
        "description": "Bundle, install, and run JavaScript & TypeScript — all in Bun. ...",
        "domain": "bun.com",
        "position": 1
      }
    ]
  },
  "creditsUsed": 0,
  "requestId": "7db121ac-d8e6-479a-b17c-59e3fe5fabd8"
}
```

With an API key, every endpoint is open. You pay in credits, only for calls that succeed. New accounts start with 500 free credits.
