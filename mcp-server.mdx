Stophy is a remote MCP server. Your agent searches for the right endpoint, reads its input, and calls it.

| --- | --- |
| No key or API key | `https://api.stophy.dev/mcp` |
| Sign in | `https://api.stophy.dev/mcp-oauth` |

Both use the Streamable HTTP transport. They are server URLs for your MCP client, not pages to open in a browser.

Stophy is also listed on [Smithery](https://smithery.ai/servers/stophy/mcp).

## How it works

Ask your agent: *"What are people saying about Bun on Reddit?"*

- It searches Stophy and finds **Reddit search**.
- It checks what Reddit search needs: a query, plus optional sort and time range.
- It gets the posts and answers you. The call used 1 credit.

Behind this are three tools: `stophy_search_endpoints`, `stophy_describe_endpoint` and `stophy_call`. Endpoint ids are camelCase, such as `redditSearch` or `youtubeSearch`. `stophy_call` takes `id`, `input` and optional `fields`, which keeps only the keys you name on each result. Lists come back as `results`, one page per call.

## Toolsets

Add `?toolsets=reddit,youtube` to the URL to also get one tool for each Reddit and YouTube endpoint.

```text
https://api.stophy.dev/mcp?toolsets=reddit,youtube
```

## Cost and limits

An MCP call costs the same credits as the same call over HTTP, and counts toward the same [rate limits](/rate-limits).
