Both are server URLs for your client, not pages to open in a browser.

## What your agent sees

Three tools. `stophy_search_endpoints` finds an endpoint, `stophy_describe_endpoint` shows its inputs, and `stophy_call` runs it. `stophy_call` takes `id`, `input` and optional `fields`, which keeps only the keys you name on each result.

Ask *"What are people saying about Bun on Reddit?"* and your agent finds `reddit.search`, calls it, and answers. A call costs the same credits as over HTTP. See [Credits and billing](/billing).

To get one tool per endpoint for some sources, add `toolsets` to the URL.

```text
https://api.stophy.dev/mcp?toolsets=reddit,youtube
```
