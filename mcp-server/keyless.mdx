## Start with no key

<McpClientSelector showSeeAll={false} />

Without a key, your agent can use three endpoints for free:

| Endpoint | What it gets |
| --- | --- |
| [Web search](/api-reference/endpoint/web-search) | Web search results |
| [YouTube search](/api-reference/endpoint/youtube-search) | YouTube videos, channels and playlists |
| [Transcript](/api-reference/endpoint/transcript) | What is said in a YouTube, TikTok or Instagram video |

## Add an API key

A key unlocks every endpoint. [Create one](https://stophy.dev/signup) and add it as a bearer token on the same URL. New accounts start with free credits to try every endpoint.

<McpClientSelector variant="key" showSeeAll={false} />

A key that is sent but wrong is refused. Remove the header to go back to free calls.

## Check the connection

Open your client's MCP status or tool list and check that `stophy` is connected: three tools, with or without a key: `stophy_search_endpoints`, `stophy_describe_endpoint` and `stophy_call`.

Then ask your agent something like:

```text
Search YouTube for "rust tutorial" and summarize the top three videos.
```

If no Stophy tools appear, restart or reload the client after you save its MCP config.
