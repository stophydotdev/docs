---
title: "Paging"
description: "Get the next page with cursor."
---

Endpoints that page say "Pages with cursor" in the [API reference](/api-reference/redditsearch).

When a response has a `cursor`, send the same input again with that `cursor` to get the next page. When there is no `cursor`, you have everything.

```ts
let cursor: string | undefined;
do {
  const response = await fetch("https://api.stophy.dev/v1/reddit/search", {
    method: "POST",
    headers: {
      authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
      "content-type": "application/json",
    },
    body: JSON.stringify({ query: "bun runtime", cursor }),
  });
  const { data } = await response.json();
  console.log(data);
  cursor = data.cursor;
} while (cursor);
```

With `Accept: text/markdown`, the last line says which `cursor` to send:

```text
More results: add "cursor": "..." to your request
```

Paging needs an API key. Without a key you get the first page only.
