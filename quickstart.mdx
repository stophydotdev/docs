## 1. Try it with no key

Google search works without a key, within a small free limit.

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

You should see JSON like this, with `creditsUsed` at `0`:

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "url": "https://bun.com/",
        "title": "Bun — A fast all-in-one JavaScript runtime",
        "description": "Bun is a fast JavaScript runtime & toolkit. All in one.",
        "position": 1
      }
    ]
  },
  "creditsUsed": 0,
  "requestId": "44eea069-e571-4dd8-95b4-cd56e641701a"
}
```

`data.results` is one page, as the site shows it. Endpoints that page take `page` (send `page: 2`, then `3`, until `data.results` is empty) or `cursor` (send back the `cursor` from the response). See [Page through results](/guides/paging).

## 2. Get an API key

Sign up at [stophy.dev/signup](https://stophy.dev/signup). New accounts start with 1,000 free credits. Create a key and store it as `STOPHY_API_KEY`. Never put it in code.
