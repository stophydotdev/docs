## 1. Try it without a key

`web.search`, `youtube.search` and `youtube.transcript` work without an API key, within free limits.

<CodeGroup>

```bash curl
curl -X POST https://api.stophy.dev/v1/web/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime","limit":5}'
```

```ts TypeScript
const response = await fetch("https://api.stophy.dev/v1/web/search", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ query: "bun runtime", limit: 5 }),
});
const { data } = await response.json();
console.log(data.results);
```

```python Python
import httpx

response = httpx.post(
    "https://api.stophy.dev/v1/web/search",
    json={"query": "bun runtime", "limit": 5},
    timeout=30,
)
print(response.json()["data"]["results"])
```

</CodeGroup>

## 2. Get an API key

Sign up at [stophy.dev/signup](https://stophy.dev/signup). New accounts start with 500 free credits. Create a key and store it as `STOPHY_API_KEY`.

## 3. Call any endpoint

With a key, all 161 endpoints are open. Send the key as a Bearer token.

<CodeGroup>

```bash curl
curl -X POST https://api.stophy.dev/v1/reddit/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

```ts TypeScript
const response = await fetch("https://api.stophy.dev/v1/reddit/search", {
  method: "POST",
  headers: {
    authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "content-type": "application/json",
  },
  body: JSON.stringify({ query: "bun runtime" }),
});
const { data, creditsUsed } = await response.json();
```

```python Python
import os
import httpx

response = httpx.post(
    "https://api.stophy.dev/v1/reddit/search",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={"query": "bun runtime"},
    timeout=30,
)
data = response.json()["data"]
```

</CodeGroup>

## Find the right endpoint

`GET https://api.stophy.dev/v1/endpoints` lists every endpoint with its input schema, its cost, whether it works without a key, and an example input when there is one. The [API reference](https://api.stophy.dev/openapi.json) has the same data as OpenAPI.
