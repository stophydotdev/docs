Make a call with no account, then add a key to get all 110 endpoints.

## Try it with no key

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime"}'
```

<Accordion title="Response">
```json
{
  "success": true,
  "data": {
    "engine": "google",
    "results": [
      {
        "type": "web",
        "url": "https://bun.com/",
        "title": "Bun — A fast all-in-one JavaScript runtime",
        "description": "Bun is a fast JavaScript runtime & toolkit. All in one. Runtime, package manager, test runner and bundler in a single binary.",
        "position": 1
      }
    ]
  },
  "creditsUsed": 0,
  "requestId": "f09d5d15-c2b2-45d3-aa5e-9868563cc9c8"
}
```
</Accordion>

`data.results` is one page of Google results, and `creditsUsed` is `0`. Without a key you get the first page only. The endpoints marked `keyless: true` in the [endpoint catalog](https://api.stophy.dev/v1/endpoints) work this way.

## Get a key

Sign up at [stophy.dev/signup](https://stophy.dev/signup). You start with 1,000 free credits. Create a key and save it as `STOPHY_API_KEY`.

The response has the same shape and costs 1 credit. Send `page: 2` to get the next page. Every endpoint is a `POST` to `https://api.stophy.dev/v1/` and its id with dots as slashes, so `youtube.transcript` is `/v1/youtube/transcript`.
