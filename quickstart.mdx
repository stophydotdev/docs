## 1. Call it without a key

`web.search`, `youtube.search` and `youtube.transcript` work without an API key, within [free limits](/without-a-key).

<CodeGroup>

```bash cURL
curl -X POST https://api.stophy.dev/v1/web/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime","limit":3}'
```

```ts Node.js
const response = await fetch("https://api.stophy.dev/v1/web/search", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ query: "bun runtime", limit: 3 }),
});
const { data } = await response.json();
for (const result of data.results) console.log(result.title, result.url);
```

```python Python
import httpx

response = httpx.post(
    "https://api.stophy.dev/v1/web/search",
    json={"query": "bun runtime", "limit": 3},
    timeout=30,
)
for result in response.json()["data"]["results"]:
    print(result["title"], result["url"])
```

</CodeGroup>

## 2. Get an API key

Sign up at [stophy.dev/signup](https://stophy.dev/signup). New accounts start with 500 free credits. Create a key and store it as `STOPHY_API_KEY`. Never put it in code.

## 3. Call any endpoint

Send the key as a Bearer token. Every endpoint is now open.

<CodeGroup>

```bash cURL
curl -X POST https://api.stophy.dev/v1/reddit/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime","limit":10}'
```

```ts Node.js
const response = await fetch("https://api.stophy.dev/v1/reddit/search", {
  method: "POST",
  headers: {
    authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "content-type": "application/json",
  },
  body: JSON.stringify({ query: "bun runtime", limit: 10 }),
});
const { data, creditsUsed } = await response.json();
```

```python Python
import os
import httpx

response = httpx.post(
    "https://api.stophy.dev/v1/reddit/search",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={"query": "bun runtime", "limit": 10},
    timeout=30,
)
data = response.json()["data"]
```
