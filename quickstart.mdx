## 1. Try it with no key

Web search works without a key, within a small free limit.

```bash
curl -X POST https://api.stophy.dev/v1/web/search \
  -H "content-type: application/json" \
  -d '{"query":"bun runtime","limit":2}'
```

You should see JSON like this, with `creditsUsed` at `0`:

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "title": "Bun — A fast all-in-one JavaScript runtime",
        "url": "https://bun.com/",
        "description": "Bundle, install, and run JavaScript & TypeScript — all in Bun.",
        "domain": "bun.com",
        "position": 1
      }
    ]
  },
  "creditsUsed": 0,
  "requestId": "0094bdbc-2935-4184-8df9-f476e561a522"
}
```

`data.results` is one page. `limit` keeps at most that many results from it. Endpoints that page also return `data.cursor`, which is how you get the next page. See [Page through results](/guides/paging).

## 2. Get an API key

Sign up at [stophy.dev/signup](https://stophy.dev/signup). New accounts start with 1,000 free credits. Create a key and store it as `STOPHY_API_KEY`. Never put it in code.
