## Prerequisites

- [Claude Desktop](https://claude.ai/download)
- Node.js 18 or later
- A Stophy API key in `STOPHY_API_KEY`. [Get one](https://stophy.dev/signup).

No key yet? Leave `env` out below to start [without one](/mcp-server/keyless).

## Add Stophy

Claude Desktop cannot connect to a remote server directly, so use the local package. It runs on your computer and forwards every call to the hosted server.

Open `claude_desktop_config.json`:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

Add Stophy to `mcpServers`:

```json
{
  "mcpServers": {
    "stophy": {
      "command": "npx",
      "args": ["-y", "@stophy/mcp"],
      "env": { "STOPHY_API_KEY": "your key" }
    }
  }
}
```

Save the file and restart Claude Desktop.

## Check it

Open the hammer icon in a new chat and check that `stophy` lists its three tools. Then try:

```text
Use Stophy to find the top Reddit posts about Bun this week and summarize them.
```

## Troubleshooting

- **No `stophy` server:** confirm the config file is valid JSON and restart Claude Desktop fully (quit, not just close the window).
- **Tool calls fail with `unauthorized`:** check the key in `env` is correct and has no extra spaces.
