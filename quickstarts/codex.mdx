Add Stophy to [Codex](https://developers.openai.com/codex) with one command.

```bash
codex mcp add stophy --url https://api.stophy.dev/mcp
```

Your agent can use the free endpoints right away. Run `codex mcp list` to check it.

## Sign in with your browser

```bash
codex mcp add stophy --url https://mcp.stophy.dev/mcp
codex mcp login stophy
```

This opens every endpoint.

## Use an API key

```bash
codex mcp add stophy --url https://api.stophy.dev/mcp --bearer-token-env-var STOPHY_API_KEY
```

Set `STOPHY_API_KEY` first. [Get a key](https://stophy.dev/signup). Codex reads it each time it starts, so it is never saved to `~/.codex/config.toml`.

## Try it

```text
Use Stophy to get the transcript of https://www.youtube.com/watch?v=dQw4w9WgXcQ and summarize it.
```

To get one tool per endpoint for some sources, see [toolsets](/mcp-server#what-your-agent-sees).
