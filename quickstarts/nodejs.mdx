## Prerequisites

- Node.js 18 or newer, which has `fetch` built in
- An API key. [Get one](https://stophy.dev/signup) and store it as `STOPHY_API_KEY`.

## Set up

```bash
npm init -y
npm pkg set type=module
npm install -D tsx
```

## A small client

```ts stophy.ts
export async function stophy<T = unknown>(id: string, input: object = {}): Promise<T> {
  const headers: Record<string, string> = { "content-type": "application/json" };
  headers.authorization = `Bearer ${process.env.STOPHY_API_KEY}`;

  const response = await fetch(`https://api.stophy.dev/v1/${id.replaceAll(".", "/")}`, {
    method: "POST",
    headers,
    body: JSON.stringify(input),
    signal: AbortSignal.timeout(30_000),
  });
  const body = await response.json();
  if (!body.success) throw new Error(`${body.error.code}: ${body.error.message}`);
  return body.data as T;
}
```

## Search the web

```ts search.ts
import { stophy } from "./stophy";

const data = await stophy<{ results: { title: string; url: string }[] }>("web.search", {
  query: "bun runtime",
  limit: 3,
});
for (const result of data.results) console.log(result.title, result.url);
```

```bash
npx tsx search.ts
```

## Call any endpoint with a key

```ts
const places = await stophy("maps.search", { query: "coffee", near: "Austin, TX", limit: 20 });
```

<Tip>The official Node SDK wraps all of this with types for every endpoint. See [Node SDK](/sdks/node).</Tip>
