Point your agent at the file that fits its job.

| Resource | Use it to |
| --- | --- |
| [agents.md](https://stophy.dev/agents.md) | Add Stophy to a project, with a client, a key and a first call. |
| [llms.txt](https://stophy.dev/llms.txt) | Find the right endpoint for a task. |
| [Docs index](https://docs.stophy.dev/llms.txt) | Find a page in these docs. |
| [OpenAPI document](https://api.stophy.dev/openapi.json) | Generate a typed client, or give a model every endpoint as a tool. |
| [MCP discovery](https://stophy.dev/.well-known/mcp.json) | Read the MCP server's tools and sign-in. |
| [Endpoint catalog](https://api.stophy.dev/v1/endpoints) | List every endpoint with its inputs, price and whether it needs a key. |

Use the **Copy page** menu on any docs page to hand its content to your agent.
