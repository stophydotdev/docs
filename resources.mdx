Point your agent at the resource that fits its task.

| Resource | Use it for |
| --- | --- |
| [agents.md](https://stophy.dev/agents.md) | Set up Stophy in a project: install a client, add a key, make a first call. |
| [llms.txt](https://stophy.dev/llms.txt) | Find the right source and endpoint for a task. |
| [Docs index](https://docs.stophy.dev/llms.txt) | Find a page in these docs. |
| [OpenAPI document](https://api.stophy.dev/openapi.json) | Generate a typed client, or give a model every endpoint as a tool schema. |
| [MCP discovery](https://stophy.dev/.well-known/mcp.json) | Read the MCP server's tools and authentication. |
| [Endpoint catalog](https://api.stophy.dev/v1/endpoints) | List endpoint inputs, costs and whether each needs a key. |

Use the **Copy page** menu on any docs page to pass its content to your agent directly.
