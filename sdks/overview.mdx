The SDKs wrap the Stophy API. Every endpoint is a typed method named after its id: `POST /v1/reddit/search` is `stophy.reddit.search(...)`. They handle auth, retries, timeouts and errors for you.

## What both SDKs do

- **No key needed to start.** Without a key, the SDK sends no `Authorization` header, so the [free endpoints](/without-a-key) work. Other endpoints raise `StophyError` with code `unauthorized`.
- **Markdown on request.** Pass `format: "markdown"` (`format="markdown"` in Python) to get a string instead of JSON.
- **Retries.** Network errors and `429`, `500`, `502`, `503`, `504` are retried with backoff, 2 times by default. `Retry-After` is honored. If the API asks to wait more than 60 seconds, the SDK raises right away with the wait in `retryAfterSeconds`.
- **Timeouts.** 30 seconds per attempt by default.
- **Errors.** Failed calls raise `StophyError` with `status`, `code`, `message`, `retryable`, `retryAfterSeconds` and `requestId`.
- **Account.** `usage()` and `logs()` read your balance and recent calls.
