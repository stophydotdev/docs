Stophy has a TypeScript SDK, a Python SDK and a CLI. Each one calls the same [API](/api-reference/introduction).

## Install

<CodeGroup>

```bash TypeScript icon="/images/icons/typescript.svg"
npm install stophy
```

```bash Python icon="python"
pip install stophy
```

```bash CLI icon="square-terminal"
npm install -g @stophy/cli
```

</CodeGroup>

## Make a call

No account, no key.

<CodeGroup>

```ts TypeScript icon="/images/icons/typescript.svg"
import { Stophy } from "stophy";

const result = await new Stophy().google.search({ query: "bun runtime" });
console.log(result.data.results);
```

```python Python icon="python"
from stophy import Stophy

result = Stophy().google.search(query="bun runtime")
print(result["data"]["results"])
```

```bash CLI icon="square-terminal"
stophy google search "bun runtime"
```

</CodeGroup>

You get Google results with `creditsUsed: 0`. A key lifts the free limit.
