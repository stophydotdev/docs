### Emails on a company's site

Leave out the name to get the emails found on the company's site, each one checked. `type` is `personal` or `generic`.

```bash cURL icon="terminal"
curl -X POST https://api.stophy.dev/v1/email/find \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "content-type: application/json" \
  -d '{"domain":"the305agency.com"}'
```

The response:

```json
{
  "success": true,
  "data": {
    "domain": "the305agency.com",
    "mxProvider": "google.com",
    "results": [
      {
        "email": "info@the305agency.com",
        "status": "valid",
        "type": "generic"
      },
      {
        "email": "info@sandra305.com",
        "status": "valid",
        "type": "generic"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "d01438d1-ab71-480e-9ea7-c3e29ea29c9e"
}
```

<Tip>You pay 1 credit only when a valid email comes back. Risky, not found and failed calls cost nothing. A role address like info@ is judged by its mail server, and `isRole` flags it.</Tip>
