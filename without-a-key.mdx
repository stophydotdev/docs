These endpoints answer without an API key:

| Endpoint | Path |
| --- | --- |
| `web.search` | `POST /v1/web/search` |
| `youtube.search` | `POST /v1/youtube/search` |
| `youtube.transcript` | `POST /v1/youtube/transcript` |

```bash
curl -X POST https://api.stophy.dev/v1/youtube/transcript \
  -H "content-type: application/json" \
  -d '{"video":"dQw4w9WgXcQ"}'
```

## Free limits

Without a key, per IP address:

- 10 requests a minute and 50 a day
- `limit` at most 10
- the first page only, with no `cursor`

When you go over, the API answers `429` with code `rateLimited` and a `Retry-After` header. A `limit` over 10 or a `cursor` answers `400`.

Calls without a key cost nothing. For more, [get an API key](https://stophy.dev/signup). New accounts start with 500 free credits.
