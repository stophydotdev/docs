These endpoints answer without an API key:

| Endpoint | What you get |
| --- | --- |
| [`web.search`](/api-reference/endpoint/web-search) | Web search results |
| [`youtube.search`](/api-reference/endpoint/youtube-search) | YouTube videos, channels and playlists |
| [`youtube.transcript`](/api-reference/endpoint/youtube-transcript) | The transcript of a YouTube video |

```bash
curl -X POST https://api.stophy.dev/v1/youtube/transcript \
  -H "content-type: application/json" \
  -d '{"video":"dQw4w9WgXcQ"}'
```

## Free limits

Without a key, per IP address:

- 10 requests a minute and 50 a day
- `limit` at most 10
- the first page only: a `cursor` is refused

Calls without a key cost nothing. The response headers show your daily allowance: `X-RateLimit-Limit` and `X-RateLimit-Remaining`.

| When | Status | Code |
| --- | --- | --- |
| You go over the free limit | `429` | `rateLimited`, with a `Retry-After` header |
| `limit` is over 10 | `400` | `invalidRequest` |
| You send a `cursor` | `400` | `invalidRequest` |
| You call any other endpoint | `401` | `unauthorized` |

Move to a key as soon as you can. [Sign up](https://stophy.dev/signup) and you start with 500 free credits.
